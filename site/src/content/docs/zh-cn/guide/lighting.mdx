**灯光**页面用于设置黑爵 AK980 V2（带屏版）按键的发光方式。右上角有两个标签页：**灯效**用于键盘自带的动画，**逐键颜色**用于你自己的设计。

<Aside type="note" title="需要 USB 数据线">
灯光设置通过 USB 数据线传输。连接数据线，并将键盘背面的开关拨到中间。使用 2.4G 接收器或蓝牙时，仍然可以选择灯效和给按键上色，但无法保存、无法实时查看按键、无法在键盘上预览，也无法使用校准测试图案。见[连接键盘](/keymotion/zh-cn/guide/connecting/)。
</Aside>

## 选择灯效

<Screenshot name="lighting-effects" alt="“灯效”标签页，已选中“流光”，右侧是它的颜色、亮度、速度和方向设置" />

<Steps>

1. 在侧边栏中打开**灯光**，选择**灯效**标签页。
2. 在**内置灯效**下点击一种灯效。它的控件会出现在**设置**面板中。
3. 调整设置。
4. 点击页面底部栏中的**保存到键盘**。键盘会切换到该灯效。

</Steps>

共有 19 种内置灯效，另外还有**关闭**。标有**按键触发**的灯效会随你打字亮起，而不是自己移动。**默认**标记的是键盘的出厂灯效“流光”，小绿点标记的是当前保存在键盘上的灯效。

| 灯效 | 设置 |
|---|---|
| **常亮** | 颜色、亮度 |
| **单键点亮**、**单键熄灭**、**星光**、**飞舞**、**呼吸**、**扩散波浪**、**爆炸**、**发射**、**涟漪**、**脉冲**、**穿梭** | 颜色、亮度、速度 |
| **滚动**、**流光**、**旋转**、**流动**、**斜雨** | 颜色、亮度、速度、方向 |
| **缤纷**、**光谱** | 亮度、速度（它们自带颜色） |
| **关闭** | 无 |

- **颜色**：点击色块，点击彩色方块选择任意颜色，或输入颜色代码（如 #FF8A3D）。选择颜色会关闭**彩虹**。
- **彩虹**：灯效使用彩虹色，而不是你选择的那种颜色。所有带颜色设置的灯效都有此选项。
- **亮度**和**速度**：从 0 到 5 共 6 级。数值越高，越亮或越快。
- **方向**：两个按移动方向命名的选项。滚动：**↓ 向下**、**↑ 向上**；流光：**→ 向右**、**← 向左**；旋转：**↺ 逆时针**、**↻ 顺时针**；流动：**→ 向前**、**← 向后**；斜雨：**↗ 右上**、**↙ 左下**。

设置下方的**恢复默认灯效**会选择“流光”并使用它的出厂设置：彩虹、亮度 5、速度 3。保存后生效。

<Aside type="caution" title="关闭">
保存**关闭**后，Fn+X 可能无法重新打开灯光。如果只想暂时关灯，改为在键盘上按 Fn+X。
</Aside>

## 实时查看按键

在**灯效**标签页中，顶部的键盘图片会显示键盘此刻正在显示的颜色。Keymotion 每秒从键盘读取约 4 次，图片下方的说明会显示**键盘实时灯光**和一个绿点。没有读数时，显示**预览**。只有 Keymotion 窗口打开时才会读取；应用在任务栏时钟旁的后台运行时不会读取。

## 为每个按键设置颜色

<Screenshot name="lighting-per-key" alt="“逐键颜色”标签页，按键上涂着“彩虹”预设" />

<Steps>

1. 选择**逐键颜色**标签页。
2. 在**画笔颜色**中选择一种颜色。
3. 使用**画笔**工具点击按键，或在按键上拖动。
4. 点击**保存到键盘**。

</Steps>

按键上方有两个工具：

- **画笔**：为你点击或拖过的每个按键上色。
- **选择**：让按键保持选中状态。点击或拖动来选择，按住 Ctrl 或 Shift 可添加或移除按键。之后你选择的每种颜色都会同时应用到所有选中的按键。提示文字旁边会出现**全选**、**熄灭所选**和**清除选择**。快捷键：Esc 清除选择，Delete 熄灭选中的按键，Ctrl+A 全选。

按键下方：

- **亮度**：0 到 5，作用于整个设计。
- **预设**：**WASD 和方向键**与**基准键行**（手指放置的 8 个按键）会用画笔颜色点亮这些按键。**彩虹**会从左到右铺开颜色。预设会替换你当前的设计。
- **全部按键**：**填充**会把每个按键涂成画笔颜色，**清除**会熄灭所有按键。

没有上色的按键保持熄灭。Num Lock 键和 Fn 键的灯光用作指示灯，因此颜色可能不会改变。

底部栏中的**在键盘上预览**开关会在你上色时把设计显示在键盘上，但不保存。此开关默认开启。离开此标签页后，键盘会恢复已保存的灯光。

## 保存或放弃更改

底部栏会显示尚未保存到键盘的内容，例如 **12 个按键已更改**、**亮度已更改**、**灯效设置已更改**或**尚未保存到键盘**。**保存到键盘**会把设置存入键盘本身，耗时不到 1 秒。**放弃更改**会恢复为键盘上已有的设置。

打开其他页面时，未保存的更改会保留在应用中，侧边栏中**灯光**旁的圆点会提示你。如果在有未保存更改时关闭窗口，Keymotion 会询问是否保存。

<Aside type="note" title="一次只保存一种灯光">
键盘上保存的要么是一种灯效，要么是一种逐键设计。保存灯效会替换键盘上的设计，保存设计也会替换灯效。Keymotion 会同时保留两者，所以你可以打开另一个标签页再保存一次。
</Aside>

[系统指标](/keymotion/zh-cn/guide/system-gauges/)开启时，键盘会显示指标，而不是你保存的灯光。页面会说明这一点，并提供按钮**前往“系统指标”**。[音乐模式](/keymotion/zh-cn/guide/music-mode/)在播放声音时也是如此，页面会提供按钮**前往“音乐模式”**。

[游戏时段](/keymotion/zh-cn/guide/game-session/)的灯光和[按应用切换的配置文件](/keymotion/zh-cn/guide/profiles/#按应用切换)也可以在一段时间内显示在按键上，而不保存任何内容。之后，你保存的灯光会恢复。

## 校准颜色

按键和屏幕显示颜色的方式不同：紫色等混合色在按键上可能比在应用中显得更淡。**设置**页面中的**颜色校准**可以让按键颜色更接近你在电脑屏幕上看到的颜色。

<Screenshot name="color-calibration" alt="“设置”中的“颜色校准”卡片，“灰阶”测试图案显示在键盘图片旁" />

- **伽马**（1.00 到 3.00，默认 2.20）决定中间调的深浅。它不会改变白色和纯色。打开**各颜色伽马**，可以分别调整红、绿、蓝滑块。
- **白平衡**设置**红**、**绿**、**蓝**的最大亮度，范围为 0 到 100%。
- **校正曲线**会将结果与虚线**未校正**进行对比。

更改会自动保存，并短暂显示**已保存**。**恢复默认设置**会把所有设置恢复为初始值。

<Steps>

1. 打开**设置**，找到**颜色校准**。
2. 在**测试图案**下选择**白色**。所有按键亮白色，电脑屏幕上也会显示同样的图案，并标有**与键盘对比**。如果白色看起来偏粉或偏蓝，调低突出的那种颜色的白平衡。
3. 选择**灰阶**：从暗到亮共 8 级灰色，应像电脑屏幕上一样均匀地逐级变亮。如果暗的几级在按键上比在电脑屏幕上亮，调高**伽马**；如果更暗，就调低它。
4. 选择**调色板**，检查橙色和紫色等混合色是否与电脑屏幕一致。
5. 选择**关闭**。你保存的灯光会恢复；离开此页面时也会恢复。
6. 打开**灯光**，重新保存你的灯效或设计。校准会应用于预览和今后保存的颜色。

</Steps>

滑块不需要数据线也能使用；测试图案需要数据线。

## 装有 3.01 固件时（测试版）

在装有黑爵 3.01 固件的 AK980 PRO 上，只有当键盘处于逐键颜色模式时，按键才会显示实时灯光。实时灯光是指 Keymotion 在按键上显示但不保存的所有内容：**在键盘上预览**、测试图案、音乐模式、系统指标、专注计时器、提醒、日历、游戏时段、AI 智能体和按应用切换的配置文件。

- 实时灯光开始时，Keymotion 会把键盘切换到逐键颜色模式。这次切换会保存到键盘上，所以 Keymotion 会像保存前一样先询问（**未经测试的固件**）。
- 实时灯光结束大约 30 秒后，Keymotion 会恢复你自己的灯光。这段等待可以在灯光频繁开关时（例如 AI 智能体）减少对键盘的写入。
- 如果你退出 Keymotion，它会在关闭前恢复你的灯光。如果程序意外退出或数据线被拔出，它会在键盘下次连接时恢复。
- 要恢复你的灯光，Keymotion 需要知道它的颜色。如果不知道，实时灯光不会显示在按键上，应用会说明原因：请在 Keymotion 中保存一次你的灯光。
- 如果你在实时灯光运行期间保存了灯效或设计，之后恢复的就是这次保存的灯光。
