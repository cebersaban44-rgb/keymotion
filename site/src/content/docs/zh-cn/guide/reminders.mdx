提醒时间一到，按键上会掠过一道该提醒颜色的波浪。如果需要，键盘屏幕上还可以显示卡片、播放提示音，Windows 也会显示通知。提醒可以只出现一次，也可以在选定的日子里定时出现，或在工作时间内每隔几分钟出现一次。

在侧边栏的**工具**下打开**提醒**。

<Screenshot name="reminders" alt="提醒页面：列表中有两条提醒，下方是设置" />

<Aside type="note" title="灯光和卡片需要 USB 数据线">
要使用按键上的波浪和屏幕卡片，连接数据线，并将键盘背面的开关拨到中间。在此期间，提醒会以 Windows 通知的形式出现。
</Aside>

## 添加提醒

添加提醒分为三步：**模板**、**内容和时间**以及**提醒方式**。在任何一步点击**取消**都会退出，不保存。

<Steps>

1. 点击**添加提醒**。
2. 选择一个模板。之后的步骤中可以更改所有内容。
   - **喝水休息**、**起身活动**和**护眼休息**分别在工作日 09:00 到 18:00 之间每隔 60、45 和 20 分钟提醒一次，只有灯光。
   - **服药**每天 14:00 提醒，有灯光和卡片。
   - **自定义提醒**只提醒一次，时间是下一个整点，有灯光和卡片。
3. 在**内容和时间**中，输入**标题**，也可以填写**备注（可选）**。然后选择**何时**：
   - **一次**：设置**日期**和**时间**。
   - **定时**：设置**时间**和**星期**。
   - **重复**：在你选择的**星期**中，于**开始**和**结束**时间之间，按**重复间隔** 20、30、45、60 或 90 分钟提醒。第一次提醒会在开始时间之后一个间隔时出现。
4. 点击**下一步**。
5. 在**提醒方式**中，选择**图标**和**颜色**，以及提醒你的方式（见下文）。
6. 点击**保存**。提醒会出现在列表中。

</Steps>

最多可以添加 20 条提醒。

## 提醒如何通知你

### 按键波浪

一道提醒颜色的波浪会掠过按键两次，用时约 3 秒。它始终开启，不需要上传，也不需要实时屏幕。点击**试一下**可以在键盘上查看效果。

### 屏幕卡片

开启**屏幕卡片**后，还会在键盘屏幕上显示一张卡片。卡片显示时间、标题、备注和下一次提醒的时间。卡片会按照**显示时长**中设置的时间停留，然后换回之前的图片。

- 卡片需要开启[实时屏幕](/keymotion/zh-cn/guide/screen/)。
- 每张卡片在每日上传上限中计为 2 次上传。页面会告诉你这条提醒每天最多使用多少次上传。对于频繁的提醒，页面会建议只用灯光。
- **卡片预览**会在页面上显示卡片，不消耗上传次数。**在键盘上试一下**会把卡片发送到键盘显示 1 分钟，计为 2 次上传。

即使开启了卡片，有时也只会点亮按键：屏幕上正在显示会议卡片、已达到每日上传上限、实时屏幕已关闭、USB 数据线未连接，或**在屏幕上显示卡片**已关闭。这时，提醒所在的一行会说明卡片没有显示的原因。

### 提示音和 Windows 通知

**通知提示音**会播放 Windows 通知提示音。在**设置**下，**Windows 通知**还会显示一条包含提醒标题和备注的 Windows 通知。键盘没有通过 USB 数据线连接时，按键无法亮起，所以这时总会显示通知。

## 你的提醒

**你的提醒**列出每条提醒的图标、标题和时间安排，用小图标表示波浪、卡片和提示音，并显示下一次提醒的时间。已经提醒过的一次性提醒会显示**已过**。每一行都有：

- **试一下**：立即演示灯光和提示音。如果开启了屏幕卡片，卡片也会发送到键盘，停留 1 分钟，并计入每日上传上限。
- **编辑**（铅笔图标）：重新打开各个步骤。
- **删除**（垃圾桶图标）：点击**删除**确认，或点击**取消**。
- 一个开关，用于开启或关闭这条提醒。

页面顶部的一行显示下一条提醒及其时间。

## 设置

- **提醒**会开启或关闭所有提醒。
- **显示时长**：卡片停留的时间，1、2 或 5 分钟。默认为 2 分钟。
- **Windows 通知**：如上文所述，为每条提醒显示 Windows 通知。
- **在屏幕上显示卡片**：关闭后，提醒只会点亮按键。
- **离开时暂停**：5 分钟没有键盘或鼠标输入后，以及屏幕锁定期间，重复提醒会暂停。你回来后，会重新开始计时。定时提醒仍会照常提醒。

<Aside type="note" title="提醒何时有效">
只要 Keymotion 在运行，提醒就有效；关闭窗口后，如果 Keymotion 继续在任务栏时钟旁运行，提醒也有效（见[设置](/keymotion/zh-cn/guide/settings/)）。它的图标菜单会显示下一条提醒，并可以开启或关闭提醒。如果某条提醒延迟超过 10 分钟（例如电脑处于睡眠状态），就会跳过这条提醒。
</Aside>
