在**自定义按键**页面中，你可以更改黑爵 AK980 V2（带屏版）每个按键的功能。按键可以发送其他按键或快捷键，用作媒体键或鼠标按键，滚动页面，播放宏，或者什么都不做。

<Screenshot name="key-mapping" alt="“自定义按键”页面，已选中 Num / 键，并在“媒体”下选择了“调高音量”" />

## 基础层和 Fn 层

右上角的两个标签页用于选择要编辑的层：

- **基础层**：单独按下按键时它的功能。
- **Fn 层**：按住 Fn 时它的功能。有些按键在这里已有内置组合键，例如用于灯光的 Fn+X。

键盘图片下方的说明会提示当前打开的是哪一层。Fn 键本身无法更改，因为 Fn 层和内置组合键都依赖它。

<Aside type="caution" title="内置 Fn 组合键">
在 Fn 层上更改的按键会失去内置组合键。将该按键设回**默认**，即可找回组合键。
</Aside>

## 更改按键

<Steps>

1. 在侧边栏中打开**自定义按键**，选择**基础层**或 **Fn 层**。
2. 在键盘图片上点击该按键。**所选按键**卡片会显示它当前的功能。
3. 在**要分配的功能**下选择一个类别：**按键**、**媒体**、**鼠标**、**宏**或**特殊**。
4. 点击要分配的功能。图片上的按键会显示新的名称。
5. 如果需要，继续更改其他按键，然后点击底部栏中的**保存到键盘**。

</Steps>

已更改的按键带有橙色边框，禁用的按键带有红色边框。小圆点标记尚未保存的按键。

## 按键可以做什么

| 类别 | 可以选择的内容 |
|---|---|
| **按键** | 任意按键，分为字母、数字、功能键、编辑、导航、符号、数字小键盘和修饰键几组。要设置 Ctrl + C 这样的快捷键，先在**同时按住**下打开 **Ctrl**、**Shift**、**Alt** 或 **Win**，再点击按键。 |
| **媒体** | 播放 / 暂停、下一曲、上一曲、停止、调高音量、调低音量和静音；媒体播放器、邮件、计算器和此电脑；以及浏览器的主页、后退、前进、停止、刷新、收藏夹和搜索。 |
| **鼠标** | 左键单击、右键单击、中键单击、后退键、前进键和双击，以及向上滚动和向下滚动。 |
| **宏** | 你的某个宏，并选择播放方式。见[宏](/keymotion/zh-cn/guide/macros/)。 |
| **特殊** | **默认**是按键的出厂功能，在 Fn 层上则是它的内置组合键。**禁用**表示按下该键不会有任何作用。 |

装有黑爵 3.01 固件时（测试版），不提供**禁用**、**双击**和宏的**按住时**播放方式：目前还不知道键盘是否支持它们。

## 撤销更改和重置层

- 所选按键下方的**恢复默认**只恢复这一个按键。
- 按键旁卡片中的**重置此层**会把当前打开的层上的所有按键恢复为出厂布局。
- 底部栏中的**放弃更改**会丢弃所有尚未保存的更改。

要把整个层恢复为出厂布局：

<Steps>

1. 选择该层的标签页。
2. 点击**重置此层**。如果这一层的所有按键已经是默认设置，此按钮会显示为灰色。
3. 点击**保存到键盘**。

</Steps>

## 保存和测试

底部栏会统计你的更改，例如 **3 个按键已更改**。**保存到键盘**会把每个更改过的层写入键盘，每层不到 1 秒，然后显示**已保存到键盘**。打开其他页面时，未保存的更改会保留在应用中，侧边栏中**自定义按键**旁的圆点会提示你。

要检查结果，点击页面底部**按键测试**卡片中的框，然后按下按键。它会显示 Windows 收到的输入：按键、快捷键、媒体键、鼠标按键和鼠标滚动。

<Aside type="note" title="页面显示的内容">
键盘无法报告自己的按键分配，因此页面显示的是你上次从 Keymotion 保存的内容及保存时间。用其他软件所做的更改不会显示在这里，而保存某一层会替换键盘上的整个层。

装有黑爵 3.01 固件时情况不同：页面显示的是从键盘本身读取的按键分配，包括在其他程序中设置的按键，并注明读取时间。被设置为 Keymotion 无法显示或更改的功能的按键会标为**在其他程序中设置**，保存时会保持原样。
</Aside>

<Aside type="note" title="需要 USB 数据线">
键盘通过 2.4G 接收器或蓝牙连接时，也可以更改按键。要保存，连接 USB 数据线，并将键盘背面的开关拨到中间。
</Aside>
