键盘连接后，**概览**是打开的第一个页面。它显示键盘此刻的灯光、屏幕上的内容，以及每个工具的状态。每个板块都可以进入对应的页面。

<Screenshot name="overview" alt="通过 USB 数据线连接时的“概览”：键盘示意图，以及屏幕、灯光、专注计时器、提醒、日历、系统指标和配置文件的板块" />

## 页面顶部

标题是键盘型号。下方是一行简短说明，例如“98% 配列、97 个按键、240×135 屏幕和旋钮”；如果键盘报告了固件版本，后面还会显示固件版本。

右侧显示连接方式（例如 **USB 有线**）和电量：

- **使用 USB 数据线时**，键盘不报告电量。Keymotion 会改为显示键盘是否正在充电：**正在充电**或**已充满**。键盘充电时 Fn 键会亮红灯，Keymotion 读取的就是这个灯光；灯光保持不变约 2 秒后，才会显示状态。将鼠标指向它，可以看到上次的蓝牙读数（如果有）。
- **使用蓝牙时**，会显示电量，例如**电量 94%**。将鼠标指向它，可以看到读取的时间。

## 键盘示意图

使用 USB 数据线时，示意图会实时显示键盘的真实灯光：Keymotion 每秒读取约 4 次。示意图下方会显示**正在实时显示键盘灯光**或**键盘灯光已关闭**。

Keymotion 窗口在前台时，你按下的按键也会在示意图中亮起（**按下的按键会在这里亮起**）。Fn 键以及 Windows 自己保留的几个按键（如 Windows 键和 Print Screen 键）不会亮起。按键上的字符跟随你在 Windows 中使用的键盘布局。

通过 2.4G 接收器或蓝牙连接时，示意图不是实时的，下方会显示**实时视图只在 USB 有线连接下可用**。

## 板块

示意图下方的每个板块都会说明对应工具当前的状态，并链接到它的页面。除了专注计时器的**开始**按钮，在这里不会更改任何东西。

- **键盘屏幕当前显示**板块显示键盘 GIF 页上的图片及其名称。实时屏幕开启时，会显示**实时屏幕已开启**和剩余的上传次数；否则显示**实时屏幕已关闭**。如果有卡片受每日上传上限限制而在等待，会显示“等待中：”和卡片名称。点击**前往“屏幕”**，可打开[屏幕](/keymotion/zh-cn/guide/screen/)页面。
- **灯光**板块显示 Keymotion 最后保存到键盘的灯效或**逐键颜色**，以及颜色和亮度（最高 5 级）。如果 Keymotion 还没有保存过任何灯光，会显示**尚未通过此应用保存**。系统指标开启时，按键会改为显示指标，板块中也会说明这一点。灯光要在[灯光](/keymotion/zh-cn/guide/lighting/)页面更改和保存；点击**前往“灯光”**，即可前往该页面。
- **专注计时器**未运行时，会概括你设置的顺序（共几段、总共多少分钟），并提供**开始**按钮。运行时，会显示当前是专注还是休息、正在进行第几段、剩余时间和一个进度条。点击**前往“专注计时器”**，可打开[专注计时器](/keymotion/zh-cn/guide/focus-timer/)页面。
- **提醒**板块的角落显示已开启的提醒数量，或显示**已关闭**；下方显示下一条提醒、它的时间以及距离现在还有多久。如果接下来没有提醒，也会说明，例如**没有即将到来的提醒**、**提醒已关闭**或**还没有提醒**。点击**前往“提醒”**，可打开[提醒](/keymotion/zh-cn/guide/reminders/)页面。
- **日历**板块显示下一场会议、它的时间以及距离开始还有多久，或显示**正在进行**。没有日历时显示**还没有添加日历**；接下来没有会议时显示**未来 24 小时内没有会议**。点击**前往“日历”**，可打开[日历](/keymotion/zh-cn/guide/calendar/)页面。
- **系统指标**板块的角落显示**已开启**或**已关闭**。开启时，实时负载条会显示按键上展示的**处理器**、**内存**和**显卡**负载。关闭时，会显示**未在按键上显示**，并列出你选择的指标。点击**前往“系统指标”**，可打开[系统指标](/keymotion/zh-cn/guide/system-gauges/)页面。
- **配置文件**板块显示与键盘当前设置相符的已保存配置文件名称，或显示**与已保存的配置文件都不匹配**。点击**前往“配置文件”**，可打开[配置文件](/keymotion/zh-cn/guide/profiles/)页面。

## 通过接收器或蓝牙连接时

键盘通过蓝牙连接时，页面底部会出现一张卡片，显示**用 USB 有线连接解锁全部功能**：灯光、自定义按键、宏和屏幕只能通过 USB 数据线设置。插入数据线并将背面的开关拨到中间后，页面会自动更新。

只插着 2.4G 接收器时，这张卡片显示**已插入 2.4G 接收器**：Keymotion 目前还无法判断键盘是否已开机并与接收器连接，更改设置同样需要 USB 数据线。出于同样的原因，顶部 **2.4G 接收器**旁边的圆点是灰色的，而不是绿色。
