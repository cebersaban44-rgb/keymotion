键盘连接后，**概览**是打开的第一个页面。它显示键盘的屏幕、键盘此刻的灯光，以及每个工具的状态。每一行都可以进入对应的页面。

## 玻璃面板

页面以键盘的玻璃面板开头，画法与 AK980 PRO 上的一样：左边是屏幕，中间是印在玻璃上的山峦图案，右边是旋钮。

- **屏幕**显示 Keymotion 放到键盘 GIF 页上的图片。如果 Keymotion 还没有放过图片，就显示键盘的时钟页和当前时间。
- **旋钮**周围有一个分为五段的橙色圆环，每段对应一级亮度，点亮到 Keymotion 上次随灯光一起保存的亮度。

面板下方有一行：键盘名称、连接方式（例如 **USB 有线**）、键盘报告时的固件版本，以及配列和按键数量。右侧是电池状态和**旋钮：亮度 5/5**：

- **通过 USB 数据线连接时**，键盘不报告电量。Keymotion 会改为显示是否正在充电：**正在充电**或**已充满**。键盘充电时会把 Fn 键点亮为红色，Keymotion 读取的就是这个灯光；灯光保持约 2 秒不变后才会显示状态。将鼠标指向它，可以看到上次通过蓝牙读取的电量（如果有）。
- **通过蓝牙连接时**，会显示电量，例如**电量 94%**。将鼠标指向它，可以看到读取的时间。

## 键盘示意图

通过 USB 数据线连接时，示意图会实时显示键盘真实的灯光：Keymotion 每秒读取约 4 次。示意图下方显示**正在实时显示键盘灯光**或**键盘灯光已关闭**。使用只点亮所按按键的灯效（例如**发射**或**涟漪**）时，两次按键之间按键保持熄灭，下方显示**打字时键盘按键会亮起**。

Keymotion 窗口位于前台时，你按下的按键也会在示意图中亮起（**按下的按键会在这里亮起。**）。Fn 和 Windows 自己保留的几个按键（如 Windows 键和 Print Screen）不会亮起。按键上的字母跟随 Windows 的键盘布局。

通过 2.4G 接收器或蓝牙连接时，示意图不会实时更新，下方显示**实时视图只在 USB 有线连接下可用**。

## 状态

**状态**下为每个工具各列一行，说明它当前在做什么；点击一行即可打开对应的页面。除了专注计时器的**开始**按钮以及提醒和系统指标的开关，这里不会更改任何设置。

- **灯光**显示 Keymotion 上次保存到键盘的效果或**逐键颜色**、颜色以及五级中的亮度；颜色显示在右侧。如果 Keymotion 还没有保存过灯光，会显示**尚未通过此应用保存**。系统指标开启时，按键会改为显示系统指标，这一行也会说明。灯光在[灯光](/keymotion/zh-cn/guide/lighting/)页面更改并保存。
- **专注计时器**未运行时，会概括你的序列（几个时段、总共多少分钟），并显示**开始**按钮。运行时，会显示当前是专注还是休息、进行到第几个时段、进度条和剩余时间。这一行会打开[专注计时器](/keymotion/zh-cn/guide/focus-timer/)页面。
- **日历**显示下一个会议、时间以及距离开始还有多久，或显示**正在进行**。没有日历时显示**还没有添加日历。**；没有即将开始的会议时显示**未来 24 小时内没有会议。** 这一行会打开[日历](/keymotion/zh-cn/guide/calendar/)页面。
- **提醒**显示下一个提醒、时间以及还有多久，右侧显示已开启的提醒数量和一个开启或关闭所有提醒的开关。没有即将到来的提醒时会说明，例如**没有即将到来的提醒。**、**提醒已关闭。**或**还没有提醒。** 这一行会打开[提醒](/keymotion/zh-cn/guide/reminders/)页面。
- **系统指标**这一行有一个开启或关闭指标的开关。开启时，显示按键上展示的**处理器**、**内存**和**显卡**负载。关闭时，显示**未在按键上显示。**并列出你选择的指标。这一行会打开[系统指标](/keymotion/zh-cn/guide/system-gauges/)页面。
- **键盘屏幕当前显示**说明键盘 GIF 页上图片的名称。实时屏幕开启时，显示**实时屏幕已开启**和剩余的上传次数；否则显示**实时屏幕已关闭**。等待每日上传次数的卡片会显示在**等待中：**之后。这一行会打开[屏幕](/keymotion/zh-cn/guide/screen/)页面。
- **配置文件**显示与键盘上内容一致的已保存配置文件名称，或显示**与任何已保存的配置文件都不匹配**。这一行会打开[配置文件](/keymotion/zh-cn/guide/profiles/)页面。

## 通过接收器或蓝牙连接时

键盘通过蓝牙连接时，键盘下方会出现一条提示栏，显示**用 USB 有线连接解锁全部功能**：灯光、自定义按键、宏和屏幕只能通过 USB 数据线设置。插入数据线并将背面的开关拨到中间后，页面会自动更新。

只插着 2.4G 接收器时，这条提示栏显示**已插入 2.4G 接收器**：Keymotion 目前还无法判断键盘是否已开机并与接收器连接，更改设置同样需要 USB 数据线。出于同样的原因，玻璃面板下方 **2.4G 接收器**旁边的圆点是灰色的，而不是绿色。
