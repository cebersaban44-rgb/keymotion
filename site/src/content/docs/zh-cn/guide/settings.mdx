**设置**中包含应用的外观和语言、关闭窗口后的行为、键盘颜色的调整、备份、更新以及获取帮助的方式。在侧边栏底部打开它。

<Screenshot name="settings" alt="设置页面顶部：“外观”以及带两个开关的“关闭和启动”" />

## 外观

- **主题**：**浅色**、**深色**或**跟随系统**。**跟随系统**会跟随 Windows 的浅色或深色模式，也是 Keymotion 初次启动时使用的设置。
- **语言**：**English**、**Türkçe**、**Русский** 或**简体中文**。整个应用会立即切换，包括任务栏时钟旁的 Keymotion 图标菜单。在你自己选择语言之前，如果 Windows 的显示语言是简体中文、土耳其语或俄语，Keymotion 就使用该语言，否则使用英语。

## 关闭和启动

灯光、自定义按键、宏和屏幕上的图片都保存在键盘中，因此关闭 Keymotion 后仍然有效。专注计时器、提醒、日历卡片、实时屏幕和按键上的指标则需要 Keymotion 保持运行。

- **关闭窗口后继续运行**默认开启。这样关闭窗口后，Keymotion 会继续运行，它的图标显示在屏幕右下角的时钟旁。Keymotion 启动后第一次关闭窗口时，Windows 通知会显示**仍在运行**。
  - 要重新打开窗口，点击该图标，或从“开始”菜单再次打开 Keymotion。
  - 要退出，右键点击该图标，然后选择**退出**。
  - 如果看不到图标，点击时钟旁的 **^** 箭头。
  - 关闭此开关后，关闭窗口就会退出 Keymotion。
- **开机时启动 Keymotion** 默认关闭。开启后，Keymotion 会在你登录 Windows 时启动，但不打开窗口，只在任务栏时钟旁显示它的图标。如果在 Windows 自己的启动设置中关闭了 Keymotion，此开关会显示为关闭并说明原因；你可以在这里重新开启。

图标的右键菜单还会显示键盘及其电量，可以控制**专注计时器**（开始、暂停、跳到下一阶段、停止），显示下一条提醒，开启或关闭**提醒**和**按键上的系统指标**，列出你的**配置文件**，还有**打开 Keymotion**。在那里选择一个配置文件，会在[配置文件](/keymotion/zh-cn/guide/profiles/)页面中打开加载确认；在你确认之前，不会保存任何内容。

如果有更改尚未保存到键盘，退出时 Keymotion 会先询问。

## 颜色校准

**颜色校准**让按键颜色更接近你在电脑屏幕上看到的颜色。所做的更改会立即保留；**恢复默认设置**会撤销这些更改。

- **伽马**决定中间调的深浅。**各颜色伽马**为红、绿、蓝各提供一个滑块。
- **白平衡**设置每种颜色的最高亮度。
- **测试图案**会让键盘显示**白色**、**灰阶**或应用的**调色板**，以便与**与键盘对比**下的示意图进行比较。它需要 USB 数据线；离开此页面后，会恢复你已保存的灯光。

校准会应用于预览和今后保存的颜色。要更新键盘上已有的颜色，在[灯光](/keymotion/zh-cn/guide/lighting/)页面中重新保存。

## 备份

- 在**导出设置**中点击**导出**，会把你的设置、自定义按键、宏和素材库保存到“下载”文件夹中的一个文件里。**在文件夹中显示**会打开该文件夹。如果添加过日历，**包含日历地址**还会把日历地址放进文件。
- 在**从备份恢复**中点击**选择文件**，会在进行任何更改之前，先显示文件的每个部分将更改什么。选择要恢复的部分，然后点击**恢复**。不会向键盘写入任何内容：灯光、自定义按键和宏会以未保存的更改打开，需要在各自的页面中保存。

<Aside type="caution" title="日历地址就像密码">
开启**包含日历地址**后，地址会以明文保存在文件中。拿到这个文件的任何人都能读取这些日历，因此不要把文件分享给他人。
</Aside>

## 更新

**关于**部分以**版本**一行开头：显示你使用的版本，以及 Keymotion 上次检查时的结果，例如已是最新版本。**检查更新**会立即在 GitHub 上检查。

在**更新**下，选择 Keymotion 自动执行的操作：

- **自动更新**：Keymotion 每天检查一次，下载新版本，并在你不使用电脑时安装（鼠标和键盘 10 分钟没有操作后）。正在写入键盘、专注计时器或[游戏时段](/keymotion/zh-cn/guide/game-session/)正在运行，或者有尚未保存到键盘的更改时，它会等待。完成后，Windows 通知会告诉你，并提供**新增内容**。
- **通知我**（推荐，也是 Keymotion 初次启动时使用的设置）：Keymotion 每天检查一次，有新版本时通知你。由你决定何时安装。
- **关闭**：Keymotion 从不自动检查。点击**检查更新**时仍会检查。

有新版本时，Keymotion 会在几个地方告诉你，这样即使窗口已关闭、它只在任务栏时钟旁运行，你也能看到：

- 一条 Windows 通知（每个版本一次），带有**立即更新**和**稍后**。**立即更新**会马上安装。Keymotion 窗口在前台时不会显示这条通知，因为窗口中的提示条会告诉你。
- 任务栏时钟旁 Keymotion 图标菜单的第一行**有可用更新**，以及图标上的一个小圆点。
- 窗口左下角的一张卡片，以及**设置**旁的一个小圆点。
- 每个页面上方的提示条。**稍后**会隐藏提示条，直到 Keymotion 下次启动。

<Steps>

1. 在提示条上或**版本**一行中点击**立即安装**。
2. 阅读**新增内容**。如果没有你所用语言的说明，**GitHub 上的发行说明**会在浏览器中打开它们。
3. 点击**安装并重启**。Keymotion 会下载新版本；**取消**会停止下载。
4. 如果正在保存到键盘，Keymotion 会等待保存完成。然后它会关闭，安装程序会在一个小窗口中显示进度，之后 Keymotion 会重新打开：如果之前窗口是打开的，就打开窗口；如果没有，就只在任务栏时钟旁运行。Windows 通知会告诉你现在安装的是哪个版本。

</Steps>

<Screenshot name="update-dialog" alt="安装新版本的窗口：当前使用的版本、发布日期、新增内容列表和“安装并重启”" />

下载的文件在安装前会经过验证。如果有尚未保存到键盘的更改，窗口会警告安装后这些更改会丢失。如果出现问题，Keymotion 会说明发生了什么，例如没有网络连接，或下载的文件无法验证；**重试**会再检查一次。

## 报告问题

<Steps>

1. 在**关于**中，点击**反馈**旁的**报告问题**。
2. **报告问题**窗口会显示**将发送的内容**：应用和 Windows 的版本、键盘及其连接方式，以及 Keymotion 日志的最新几行。其中不包含网址和你的 Windows 用户名。
3. 点击**在 GitHub 上报告**。详细信息会复制到剪贴板，浏览器中会打开项目的问题表单。发送需要 GitHub 账号。
4. 描述发生了什么，用 Ctrl+V 将详细信息粘贴到表单的详细信息框中，然后提交表单。

</Steps>

<Screenshot name="report-dialog" alt="“报告问题”窗口：将发送的详细信息，以及“复制”和“在 GitHub 上报告”按钮" />

如果你想用其他方式发送，**复制**会把相同的文本放到剪贴板，而不打开 GitHub。Keymotion 本身从不发送任何内容。

Keymotion 也会主动提供这个窗口。发生意外错误后，会出现**出现了意外问题**的通知，并提供**报告问题**。应用崩溃后，下次启动时会显示一次 **Keymotion 上次运行时出现了问题**，并提供**报告**。

## “关于”中的其他内容

<Screenshot name="settings-about" alt="设置中的“关于”部分：带“检查更新”的“版本”、有三个选项的“更新”（已选择“通知我”）、“窗口外观”、“使用指南”、“反馈”和“诊断信息”" />

- **反馈**旁的**提出建议**会在 GitHub 上打开项目的建议表单。
- 在**诊断信息**中点击**复制**，会把同类报告放到剪贴板，方便你在自己写的消息中附上。不包含日历地址和个人信息。
- **日志文件**和**数据文件夹**各有一个**打开文件夹**，分别打开保存最近 7 天日志和崩溃记录（如有）的文件夹，以及保存你的设置和素材库的文件夹。
- **窗口外观**显示为**纯色**或**半透明（Windows 11）**。Keymotion 会根据你的 Windows 版本自动选择，无需设置。
- **隐私**说明应用不收集也不发送使用数据，只在读取你添加的日历和在 GitHub 上检查新版本时联网。详见[隐私](/keymotion/zh-cn/about/privacy/)。
