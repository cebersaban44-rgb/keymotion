## 当前连接

第一张卡片显示连接方式（**USB 有线**、**2.4G 接收器**或**蓝牙**），并用一句话说明这种连接下能做什么：

| 连接方式 | 页面上的说明 |
|---|---|
| USB 有线 | **应用的所有功能都可以使用。** |
| 2.4G 接收器 | **2.4G 接收器已插入，但 Keymotion 目前还无法判断键盘是否已开机并与接收器连接。只有在 USB 有线连接下才能更改设置。** |
| 蓝牙 | **键盘可以正常使用。此连接下只读取电量。** |

Keymotion 目前还不向接收器发送任何内容，因此看不到接收器后面的键盘。如果键盘通过蓝牙连接而接收器仍插着，页面会显示**蓝牙**。

下方是键盘的信息：**设备**（键盘型号），使用数据线时还有**固件**版本。使用蓝牙时，会显示**蓝牙名称**、键盘当前所在的**通道**（键盘共有 3 个蓝牙通道）以及**蓝牙地址**。

右侧的**键盘上的开关**会按当前档位画出键盘背面的开关。它只是一张图，不是控件，图下写着**用这个开关切换连接方式**。这三个档位的说明见[连接键盘](/keymotion/zh-cn/guide/connecting/)。

## 各连接方式的功能

表格列出了 Keymotion 通过 USB 数据线、2.4G 接收器和蓝牙分别能做什么。当前连接所在的列标记为**当前**。

- 对勾表示**可用**，短横线表示**不可用**。
- 电量一行中的**上次读数**表示：使用数据线时，Keymotion 显示的是上次通过蓝牙读取的电量。

表格下方有两条说明：实时灯光和卡片包括专注计时器、系统指标、提醒、日历和“正在播放”；只有通过 USB 数据线连接、且背面的开关位于中间时，才能更改设置。

<Aside type="note" title="装有 3.01 固件时（测试版）">
装有黑爵 3.01 固件时，**固件**显示 3.01 并标为**测试版**，旁边还有一段说明这项支持是新的。下方的**测试向导**会显示你在[测试向导](/keymotion/zh-cn/help/keyboards/#测试向导)中完成了多少，**打开向导**会打开它。由于键盘通过数据线也会报告电量，键盘信息中还会显示**电池**，使用数据线时同样可以看到电量。**键盘备份**下会列出 Keymotion 为键盘保存的备份：参见[装有 3.01 固件时的键盘备份](/keymotion/zh-cn/help/recovery/#装有-301-固件时的键盘备份)。**键盘时钟**卡片不会说同步会让屏幕切换到时钟页：在这个固件上还不知道是否如此。
</Aside>

## 键盘时钟

键盘屏幕上有一个时钟页。**键盘时钟**卡片负责让它保持准确。

- 卡片会显示时钟上次同步是在多久以前，或显示**尚未同步**。将鼠标指向它，可以看到确切的日期和时间。
- **立即同步**会将键盘时钟设为电脑的时间。同步还会让键盘屏幕切换到时钟页。
- **连接时同步**会在键盘通过 USB 连接时自动同步，每天最多一次。此选项默认开启。
- 如果键盘固件版本没有在 Keymotion 上测试过，时钟会等待你的同意：Keymotion 会像保存前一样询问**未经测试的固件**，只有在你单击**继续**后才设置时钟。

通过 2.4G 接收器或蓝牙连接时，卡片上会显示**如需同步，连接数据线，并将键盘背面的开关拨到中间**，**立即同步**也无法点击。

<Aside type="note">
没有连接键盘时，此页面会改为显示欢迎页面。见[首次启动](/keymotion/zh-cn/guide/first-launch/)。
</Aside>
