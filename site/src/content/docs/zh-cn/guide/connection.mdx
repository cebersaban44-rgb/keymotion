<Screenshot name="connection" alt="通过 USB 数据线连接时的“连接”页面：当前连接、位于 USB 档的开关示意图、功能表和键盘时钟" />

## 当前连接

第一张卡片显示连接方式（**USB 有线**、**2.4G 接收器**或**蓝牙**），并用一句话说明这种连接下能做什么：

| 连接方式 | 页面上的说明 |
|---|---|
| USB 有线 | **应用的所有功能都可以使用。** |
| 2.4G 接收器 | **键盘可以正常使用，但目前还无法通过此连接更改设置。** |
| 蓝牙 | **键盘可以正常使用。此连接下只读取电量。** |

下方是键盘的信息：**设备**（键盘型号），使用数据线时还有**固件**版本。使用蓝牙时，会显示**蓝牙名称**、键盘当前所在的**通道**（键盘共有 3 个蓝牙通道）以及**蓝牙地址**。

右侧的**键盘上的开关**会按当前档位画出键盘背面的开关。它只是一张图，不是控件，图下写着**用这个开关切换连接方式**。这三个档位的说明见[连接键盘](/keymotion/zh-cn/guide/connecting/)。

## 各连接方式的功能

表格列出了 Keymotion 通过 USB 数据线、2.4G 接收器和蓝牙分别能做什么。当前连接所在的列标记为**当前**。

- 对勾表示**可用**，短横线表示**不可用**。
- 电量一行中的**上次读数**表示：使用数据线时，Keymotion 显示的是上次通过蓝牙读取的电量。

表格下方有两条说明：实时灯光和卡片包括专注计时器、系统指标、提醒、日历和“正在播放”；只有通过 USB 数据线连接、且背面的开关位于中间时，才能更改设置。

## 键盘时钟

键盘屏幕上有一个时钟页。**键盘时钟**卡片负责让它保持准确。

- 卡片会显示时钟上次同步是在多久以前，或显示**尚未同步**。将鼠标指向它，可以看到确切的日期和时间。
- **立即同步**会将键盘时钟设为电脑的时间。同步还会让键盘屏幕切换到时钟页。
- **连接时同步**会在键盘通过 USB 连接时自动同步，每天最多一次。此选项默认开启。

通过 2.4G 接收器或蓝牙连接时，卡片上会显示**如需同步，连接数据线，并将键盘背面的开关拨到中间**，**立即同步**也无法点击。
