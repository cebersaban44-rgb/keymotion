## Keymotion 是什么？

Keymotion 是一款用于黑爵 AK980 V2（带屏版）键盘的免费开源 Windows 应用。你不需要 AJAZZ（黑爵）自家的软件，也就是常说的黑爵官方驱动：Keymotion 会通过 USB 数据线，自己完成灯光、自定义按键、宏和屏幕的设置。这款键盘在 Windows 中显示的 USB 名称为 SONiX AK980 PRO。2026 款 AK980 PRO（原生双 8K）是另一款键盘，Keymotion 不支持。

<Screenshot name="overview" alt="黑爵 AK980 V2（带屏版）通过 USB 有线连接时 Keymotion 的“概览”页面" />

| 概况 | |
|---|---|
| 价格 | 免费，无需账号 |
| 许可证 | MIT 或 Apache-2.0，源代码在 GitHub 上 |
| Windows | 64 位 Windows 10 和 11 |
| 语言 | 英语、土耳其语、俄语和简体中文 |
| 键盘 | 黑爵 AK980 V2（带屏版），USB 名称为 SONiX AK980 PRO |
| 设置方式 | 通过 USB 数据线 |
| 获取方式 | 从 [Microsoft Store](https://apps.microsoft.com/detail/9NL03GDZZ0ZS?referrer=appbadge&mode=full) 获取（由 Microsoft 签名），或从 [GitHub](https://github.com/cebersaban44-rgb/keymotion/releases/latest) 下载安装程序（尚未签名）：[如何选择](/keymotion/zh-cn/guide/install/) |

  <Card title="屏幕编辑" icon="window">

  <Card title="实时屏幕" icon="analytics">

  <Card title="专注和提醒" icon="clock">

## 各连接方式下可用的功能

连接方式由键盘背面的开关选择。设置只能通过 USB 数据线传输，这是键盘本身的设计。

| 连接方式 | 黑爵 AK980 V2（带屏版） |
|---|---|
| USB 有线 | 全部功能：灯光、按键、宏、屏幕和实时卡片 |
| 2.4G 接收器 | 打字、媒体键和旋钮 |
| 蓝牙 | 打字、媒体键、旋钮和电量 |
