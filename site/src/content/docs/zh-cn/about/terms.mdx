Keymotion 是一款免费的 Windows 桌面应用，用于控制你的键盘：灯光、自定义按键、宏、屏幕和时钟。这些条款说明你可以对它有哪些期待，以及它对你有哪些要求。最后修改日期：2026 年 11 月 16 日。

## 免费开源

- Keymotion 完全免费。没有账户、没有广告，也没有付费版本。
- 它的源代码在 [GitHub](https://github.com/cebersaban44-rgb/keymotion) 上公开。你可以按照 [MIT 许可证](https://github.com/cebersaban44-rgb/keymotion/blob/main/LICENSE-MIT)或 [Apache 许可证 2.0](https://github.com/cebersaban44-rgb/keymotion/blob/main/LICENSE-APACHE)（任选其一）使用、复制、修改和分享它。这些许可证是软件本身的法律条款；本页不会改变它们。
- 你可以从 GitHub 或 Microsoft Store 下载它。两者是同一个应用。对于从 Microsoft Store 获取的版本，Microsoft Store 自己的条款同样适用。

## 无担保

正如两种许可证所述，Keymotion 按“原样”提供，不附带任何形式的担保。没有人保证它能用于你的键盘或满足你的用途，也没有人对使用它造成的损害承担责任。

当你保存灯光、自定义按键、宏或图片时，Keymotion 会写入键盘自己的存储空间。它与这些键盘通信的方式来自对键盘的实际测量，而不是制造商公开的文档。如果出现问题，[出现问题时](/keymotion/zh-cn/help/recovery/)页面说明了如何让键盘恢复到之前的状态。

## 你的键盘及其制造商

Keymotion 是一个独立项目。它不是由 AJAZZ（黑爵）、AULA（狼蛛）或任何其他键盘品牌、键盘主控芯片的制造商或键盘官方驱动的作者制作的，也没有得到他们的认可、赞助或支持。产品名称仅用于说明 Keymotion 适用于哪些硬件。

## 游戏

- Keymotion 不读取也不修改任何游戏的内存，不向游戏发送按键，也不加载任何驱动。它会查看哪个程序在前台，读取你的启动器中的游戏列表；在英雄联盟对局中，它会读取游戏本身在你电脑上提供的对局数据。[游戏时段](/keymotion/zh-cn/guide/game-session/)页面介绍了具体方式。
- 每个游戏和比赛都有自己的规则。即使是存储在键盘上的宏，也可能违反竞技游戏的规则。是否遵守这些规则，由你自己负责。如果某个游戏的反作弊程序出现问题，在**游戏时段**页面开启**游戏时不向键盘发送任何内容**。

## 其他公司的服务

Keymotion 会读取你添加的日历，并在 GitHub 上检查更新。使用这些功能时，相关服务的条款和隐私政策同样适用。Keymotion 读取和发送哪些内容，见[隐私政策](/keymotion/zh-cn/about/privacy/)页面。

## 名称和商标

Windows、Microsoft Store、Steam、Epic Games、GOG、Xbox、英雄联盟（League of Legends）等名称以及各键盘品牌均归其各自所有者所有。Keymotion 使用这些名称，只是为了说明它适用于哪些产品。
