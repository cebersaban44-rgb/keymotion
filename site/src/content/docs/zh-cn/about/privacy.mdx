Keymotion 是一款桌面应用，用于控制你的键盘（灯光、自定义按键、宏、屏幕和时钟），并在键盘上显示信息。它所做的一切都在你的电脑上进行。

## 不收集使用数据

- Keymotion 不收集使用数据、统计信息或崩溃报告，也不会把任何关于你或你电脑的信息发送到任何地方。
- 没有账户，也无需登录。
- 日志文件和崩溃记录保存在你的电脑上（参见[你的数据存放在哪里](#你的数据存放在哪里)）。

## Keymotion 何时联网

Keymotion 只为两件事连接互联网：你添加的日历和更新检查。除此之外，它不建立任何网络连接。

### 你添加的日历

- Keymotion 每 15 分钟读取一次你添加的每个日历地址，你要求时也会读取。只要它在运行，就会持续读取，包括窗口已关闭、只在任务栏时钟旁显示图标运行的时候。
- 它只读取日历，不会向日历服务器发送其他任何内容。
- 它使用 Windows 自身的网络连接，因此系统的代理和证书设置同样适用。
- 只接受安全的 `https://` 地址。`webcal://` 地址会按 `https://` 读取。

### 更新检查

- **何时检查**。除非在**设置**的**关于**部分把**更新**设为**关闭**（初始为**通知我**），否则 Keymotion 每天最多检查一次：启动后不久检查一次，之后在持续运行期间每天检查一次。同一位置的**检查更新**可以随时执行同样的检查。设为**关闭**时，Keymotion 只在你单击该按钮时检查。
- **读取什么**。从项目在 GitHub 上的发布页面读取一个小文件 `latest.json`。请求发往 `github.com`，文件来自 GitHub 的下载服务器。
- **发送什么**。一个普通的下载请求。除了更新组件的名称和版本（`tauri-plugin-updater`）之外，其中不包含任何关于你的信息：没有账户、使用数据或设置。和任何服务器一样，GitHub 能看到请求来源的 IP 地址。
- **发现新版本时**。设为**通知我**时，Keymotion 会询问你；设为**自动更新**时，它会下载新版本，并在电脑无人使用时安装。无论哪种方式，安装程序都来自 GitHub，并会用 Keymotion 内置的公钥验证它的签名。如果签名不匹配，就不会安装。
- **测试版**。版本号带后缀（例如“-rc”）的版本还会读取 GitHub 的公开发布列表（`api.github.com`），以便也能看到测试版本。正式版本不会读取该列表。
- **Microsoft Store 版**。从 Microsoft Store 安装的 Keymotion 从不执行这项检查：它由 Microsoft Store 负责更新。

## 其他公司的隐私政策

Keymotion 本身不会发送任何关于你的信息。当你使用以下服务时，它们会看到一个普通的请求，并适用它们自己的隐私政策：

- **GitHub**：更新检查、下载，以及报告问题或申请适配。参见 [GitHub 一般隐私声明](https://docs.github.com/zh/site-policy/privacy-policies/github-general-privacy-statement)。
- **Microsoft**：如果电脑上没有 WebView2（Windows 中负责绘制应用窗口的组件），安装程序会从 Microsoft 下载并安装它。Windows 11 已经自带。参见 [Microsoft 隐私声明](https://www.microsoft.com/zh-cn/privacy/privacystatement)。
- **你添加的每个日历所属的服务**，例如 [Google](https://policies.google.com/privacy?hl=zh-CN)、[Microsoft Outlook](https://www.microsoft.com/zh-cn/privacy/privacystatement) 或 [Apple iCloud](https://www.apple.com.cn/legal/privacy/)。

## Keymotion 在你的电脑上读取哪些信息

这些读取的信息只用于在键盘和应用中显示内容。除注明之外，它们不会被保存，也绝不会离开你的电脑。

| 内容 | 何时 | 用途 |
|---|---|---|
| 正在播放的歌曲（标题、艺术家、封面、播放的应用），来自 Windows | 实时屏幕及其**正在播放**来源开启时 | 键盘屏幕上的歌曲卡片 |
| 处理器、显卡和内存负载，来自 Windows 的性能计数器 | 系统指标开启时，或其页面打开时 | 按键上的负载条 |
| 扬声器音量和静音状态、麦克风静音状态，来自 Windows 的声音系统 | 系统指标开启时，或其页面打开时 | 音量条和静音指示灯 |
| 电脑正在播放的声音此刻的响度，来自 Windows 的声音系统（发往扬声器或耳机的混合声音；从不读取麦克风） | 音乐模式开启时，或其页面打开时 | 按键上的音乐灯光。不会录制、存储或向任何地方发送声音；只短暂保留它的响度 |
| 距你上次使用键盘或鼠标的时间 | 提醒开启时 | 你不在时，重复提醒会等待 |
| 哪个程序在前台：它的文件名和文件夹，以及它的窗口是否占满屏幕。从不读取窗口标题，也不会打开任何程序 | **识别游戏**或配置文件的**按应用切换**开启时 | 区分游戏和其他程序，以及为每个程序切换配置文件 |
| 程序的图标，从它的文件中读取（不会打开该程序） | 游戏或程序列表中显示它时，以及没有 Steam 图片（或图片无法读取）的游戏启动时 | 列表中和开局卡片上的图标 |
| 你的启动器中的游戏列表（Steam、Epic Games、GOG、Xbox、Riot Games、Xbox Game Bar） | **识别游戏**开启时，每隔几分钟 | 判断哪些程序是游戏 |
| 处理器和显卡负载，以及显卡温度 | 游戏时段进行期间 | 结算卡片和历史记录 |
| 英雄联盟的对局数据（你的生命值、法力值、等级、得分、对局中的事件，以及按记分板上显示的名称判断哪些玩家在己方），来自游戏在你电脑上运行的服务 | 英雄联盟对局期间，其灯光开启时 | 灯光和结算卡片 |
| 你的 Windows 键盘布局 | 应用打开或切换到前台时 | 用你的语言显示按键标签 |
| 已连接的键盘（USB 设备、蓝牙电量） | 应用运行期间 | 查找并控制键盘 |
| 键盘的 HID 描述（Windows 记录的关于它的信息） | 你为尚未支持的键盘申请适配时 | 适配申请 |
| Windows 和 WebView2 的版本 | 你复制诊断信息或报告问题时 | 诊断信息文本 |

## 你的数据存放在哪里

所有内容都在你的 Windows 用户文件夹中。在**设置**的**关于**部分，**数据文件夹**和**日志文件**可以打开这些文件夹。

- **设置和记录**，位于 `%APPDATA%\dev.keymotion\`：
  - `calibration.json`、`clock.json`、`lighting.json`、`pomodoro.json`、`gauges.json`、`music.json`、`reminders.json`、`battery.json`、`profiles.json`、`background.json`、`updates.json`、`games.json`；
  - `auto-profiles.json`：你的**按应用切换**配置文件；以及在为某个程序把配置文件保存到键盘之后，保存之前键盘上的灯光、自定义按键和宏的一份副本，用于恢复之前的状态；
  - `game-history.json`：你的游戏时段（游戏、开始和结束时间、读取的数值、英雄联盟的对局结果）。**游戏时段**页面上的**删除历史记录**会清空它；
  - `keymap.json` 和 `macros.json`：Keymotion 对已写入键盘内容的唯一记录，因为键盘无法回报这些设置；
  - `calendar.json`：你的日历。日历地址的作用相当于密码，因此会针对你的 Windows 用户账户加密（Windows 数据保护）。其他用户或其他电脑无法读取它们；
  - `screen\`：你的图片素材库、出厂动画的副本（如果你做过），以及最近一张实时卡片。
- **日志文件**，位于 `%LOCALAPPDATA%\dev.keymotion\logs\`：每天一个文件，保留最近 7 天，每个最多 4 MB；另有简短的崩溃记录。写入之前，网址会被截短为服务器名称，你的 Windows 用户名会从文件夹路径中删除。提醒标题和会议名称从不写入。
- **界面偏好**，位于 `%LOCALAPPDATA%\dev.keymotion\EBWebView\`：主题、语言和尚未保存的编辑，由应用窗口保存。

从 Microsoft Store 安装的 Keymotion 使用同样的文件夹。如果这些文件夹之前不存在（从未安装过 GitHub 版 Keymotion），Windows 会把它们保存在应用自己的文件夹 `%LOCALAPPDATA%\Packages\<应用的包名>\LocalCache\` 中，并在你卸载应用时删除；此时**设置**中的按钮会打开该文件夹。

## 诊断信息

在**设置**的**关于**部分，**诊断信息**旁边的**复制**会把一段文本放到剪贴板上：应用、Windows 和 WebView2 的版本，键盘型号、固件和连接方式，设置文件的名称和大小，以及日志的最后 150 行（已按上述方式清理）。这段文本不会被发送到任何地方。是否把它粘贴到消息中，由你决定。

## 报告问题或申请适配

问题由你自己在 GitHub 上报告。Keymotion 不会自行发送任何内容。

- **报告问题**（位于**设置**的**关于** › **反馈**；意外错误之后的提示中；崩溃之后的提示中）会打开一个窗口，先显示文本：上述诊断信息，最上方是发生的情况。**在 GitHub 上报告**会把文本放到剪贴板上，并在浏览器中打开项目在 GitHub 上的表单。你在那里粘贴，并决定是否提交。
- **申请适配**会在尚未支持的 SONiX 或 AJAZZ（黑爵）键盘连接时出现。它的工作方式相同，文本中包含键盘的信息：USB 标识符、名称以及 Windows 保存的 HID 描述。不会向键盘写入任何内容。序列号和设备路径不会包含在内。
- **崩溃之后**，下次启动时会提供最近 7 天内最新的一条崩溃记录，只提供一次。

## 导出、导入和删除

- **导出**。在**设置**中，**备份**下的**导出**会在你的“下载”文件夹中保存一个 JSON 文件，其中包含你的设置、自定义按键和宏的记录、提醒、日历设置、灯光和图片素材库。只有开启**包含日历地址**时，才会包含日历地址。这样它们会以明文形式保存在文件中，所以请妥善保管这个文件，不要分享给别人。
- **导入**。**备份**下的**选择文件**会在做出任何更改之前，先显示文件中包含哪些内容、将要替换哪些内容。导入不会向键盘写入任何内容：自定义按键、宏和灯光会作为未保存的更改打开，由你来保存。
- **删除**。卸载 Keymotion 时勾选 **Also delete my settings and saved data**（同时删除我的设置和已保存的数据），或者在卸载后自己删除上述文件夹。你也可以在 Keymotion 关闭时删除单个文件；之后它会以默认设置重新启动。

## 哪些内容会留在键盘上

键盘会把一些设置保存在自己的存储空间中。卸载 Keymotion 或把键盘连接到其他电脑后，这些设置仍会保留：

- 自定义按键和宏；
- 灯效或逐键颜色设计；
- 屏幕上的图片；
- 时钟。

如果要在把键盘送人之前清除这些内容，重置自定义按键，删除宏并保存，然后用 Keymotion 上传一张中性的图片。参见[出现问题时](/keymotion/zh-cn/help/recovery/)。
