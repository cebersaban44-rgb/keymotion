Keymotion 支持**黑爵 AK980 V2（带屏版）**，它的 USB 名称为 SONiX AK980 PRO。很多键盘基于同一平台打造：芯片类型相同，命令相同，厂商程序也常常相同，只是以不同的名称销售。这些键盘之后有可能得到支持，但每一款都要等有人实际试过之后才会加入，因为保证键盘安全的细节因型号而异。

## 已测试，可用

<Image src={ak980} alt="黑爵 AK980 V2（带屏版）" width={520} />

| 键盘 | USB 有线 | 2.4G 接收器 | 蓝牙 | 状态 |
|---|---|---|---|---|
| **黑爵 AK980 V2（带屏版）** | 全部功能 | 打字、媒体键和旋钮 | 打字、媒体键、旋钮和电量 | <span class="km-status" data-s="works">可用 · 已测试</span> |

这款键盘在不同商店里不止一个名称。Keymotion 测试所用的键盘购自 AJAZZ（黑爵）自己的店铺，商品名为“AK980MAX … V2”，包装盒上写着 **AK980 V2**。通过 USB 连接时，它报告的厂商是 SONiX，名称是“AK980 PRO”，Keymotion 正是根据这个名称识别它。所以，带屏幕的**黑爵 AK980 V2** 可以使用。其他 AK980 版本（例如不带屏幕的版本）内部可能不同。只有报告这个名称、并且在连接时的检查中确认内部结构相同的键盘，Keymotion 才会把它当作这款键盘；否则不会向它发送任何内容，而是提供**申请适配**。2026 款 AK980 PRO（原生双 8K）是另一款键盘，Keymotion 不支持。

Keymotion 在键盘固件 1.06 上经过测试；在其他版本上，它会在向键盘保存任何内容之前先询问你。黑爵为 AK980 PRO 推出的最新固件 3.01（“AK980 Led v2 Firmware 769”）使用另一套命令，Keymotion 暂不支持：它不会向装有这个固件的键盘发送任何内容，黑爵也没有提供退回旧固件的方法。参见[要安装黑爵最新的固件吗？](/keymotion/zh-cn/help/faq/#要安装黑爵最新的固件吗)

设置通过 USB 数据线传输，这是由键盘本身的设计决定的。[连接键盘](/keymotion/zh-cn/guide/connecting/)页面介绍了三种连接方式。

你的键盘不在列表中？也可以先插上试试：如果 Keymotion 显示**申请适配**，[把它的信息发给我们](https://github.com/cebersaban44-rgb/keymotion/issues/new?template=keyboard.yml)。

<Aside type="caution" title="为什么不直接开放支持">
这些键盘对收到的内容不加检查就会接受。在一台 AULA F108 Pro 上，一段超出上限的屏幕动画永久覆盖了键盘自带的菜单图片。每个型号的上限都不同（107、140、141 或 255 帧），所以一个型号只有在测量出它自己的上限之后才会加入。
</Aside>

### 键盘如何逐步获得支持

1. 有这款键盘的人通过**申请适配**或[键盘表单](https://github.com/cebersaban44-rgb/keymotion/issues/new?template=keyboard.yml)发送它的信息。
2. 我们在 Keymotion 中描述这个型号，并为它准备一个测试版本。
3. 测试者逐项试过每个功能并反馈结果。每份反馈都会在 GitHub 上用 `keyboard support` 标签跟踪。
4. 所有功能都试过之后，这个型号会移到**已测试，可用**，并注明每种连接方式下可以使用的功能。

状态一栏从**尚未测试**变为**测试中**，然后是**可用**或**不可用**。

## 外观相似，内部不同

有些键盘看起来像黑爵 AK980 V2（带屏版），或者与本页某款键盘同名，但使用的是另一种芯片或另一种命令体系。Keymotion 从不向它们发送任何内容。

| 键盘 | 不同之处 |
|---|---|
| AK980 MAX（磁轴） | 另一种命令体系 |
| 黑爵 AK820 Pro，固件版本为 1.07 或 1.16 的版本 | 另一种命令体系 |
| 黑爵 AK820 MAX，使用网页设置工具的版本（包括 MAX HE） | 另一种命令体系 |
| 黑爵 AK820 Max Plus（SinoWealth 版本）、AK820（非 Pro 版）、AK992 | 另一种芯片 |
| AULA F75、F87、F87 Pro、F99、F99 Pro | 另一种芯片 |
| AULA F87S 8K、Nova98；黑爵 AK680 V2 / MAX | 另一种命令体系 |
| 黑爵 AKS068 | VIA/QMK 键盘 |

尚不清楚的型号：黑爵 AK870 V2、AK820 MAX Ultra、AK870、AK873、AK966 和 AULA F99 Max。如果你有其中一款，[发送它的信息](https://github.com/cebersaban44-rgb/keymotion/issues/new?template=keyboard.yml)，我们来弄清楚。
