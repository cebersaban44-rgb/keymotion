Keymotion 支持**黑爵 AK980 V2（带屏版）**，它的 USB 名称为 SONiX AK980 PRO。很多键盘基于同一平台打造：芯片类型相同，命令相同，厂商程序也常常相同，只是以不同的名称销售。这些键盘之后有可能得到支持，但每一款都要等有人实际试过之后才会加入，因为保证键盘安全的细节因型号而异。

## 已测试，可用

<Image src={ak980} alt="黑爵 AK980 V2（带屏版）" width={520} />

| 键盘 | USB 有线 | 2.4G 接收器 | 蓝牙 | 状态 |
|---|---|---|---|---|
| **黑爵 AK980 V2（带屏版）** | 全部功能 | 打字、媒体键和旋钮 | 打字、媒体键、旋钮和电量 | <span class="km-status" data-s="works">可用 · 已测试</span> |

这款键盘在不同商店里不止一个名称。Keymotion 测试所用的键盘购自 AJAZZ（黑爵）自己的店铺，商品名为“AK980MAX … V2”，包装盒上写着 **AK980 V2**。通过 USB 连接时，它报告的厂商是 SONiX，名称是“AK980 PRO”，Keymotion 正是根据这个名称识别它。所以，带屏幕的**黑爵 AK980 V2** 可以使用。其他 AK980 版本（例如不带屏幕的版本）内部可能不同。只有报告这个名称、并且在连接时的检查中确认内部结构相同的键盘，Keymotion 才会把它当作这款键盘；否则不会向它发送任何内容，而是提供**申请适配**。2026 款 AK980 PRO（原生双 8K）是另一款键盘，Keymotion 不支持。

Keymotion 在键盘固件 1.06 上经过测试；在其他版本上，它会在向键盘保存任何内容之前先询问你。黑爵最新的固件 3.01 使用另一套命令；Keymotion 以测试版形式支持它，详见[下文](#装有-301-固件的-ak980-pro测试版)。

设置通过 USB 数据线传输，这是由键盘本身的设计决定的。[连接键盘](/keymotion/zh-cn/guide/connecting/)页面介绍了三种连接方式。

## 装有 3.01 固件的 AK980 PRO（测试版）

黑爵为 AK980 PRO 推出的最新固件 3.01（“AK980 Led v2 Firmware 769”）会把键盘切换到另一套命令。Keymotion 以测试版形式支持它，需通过 USB 数据线连接。要查看键盘装的是哪个固件，连接数据线并打开**连接**页面：键盘信息中的**固件**一项会显示版本。装有 3.01 固件时，**概览**和**连接**页面会把它标为**测试版**。

| 连接方式 | 装有 3.01 固件时 Keymotion 做什么 |
|---|---|
| USB 有线 | 灯效和逐键颜色、实时灯光、两层的自定义按键、宏、屏幕图片、时钟和电量 |
| 2.4G 接收器 | 没有变化：和旧固件一样，不通过接收器发送任何内容 |
| 蓝牙 | 和以前一样：读取电量 |

测试版的意思是这项支持是新的，仍在测试中。所以 Keymotion 对它格外谨慎：

- 在能够写入任何内容之前，它会先保存一份键盘设置的备份，之后可以用来恢复。
- 第一次向键盘写入之前，它会先询问你，和对待任何未在 Keymotion 上测试过的固件一样。
- 它保存的每项设置（自定义按键、灯光、宏）都会读回检查。键盘开机或重置后的一小段时间内会忽略写入，所以 Keymotion 会等一会儿再进行第一次写入。
- 如果键盘报告的内容看起来不符合预期，Keymotion 不会向键盘写入任何内容，并会在页面顶部说明原因；参见[出现问题时](/keymotion/zh-cn/help/recovery/#keymotion-不向键盘写入任何内容时)。键盘上没有逐键颜色（例如固件更新之后，或用黑爵网页工具重置之后）是正常的，不会妨碍写入。

这个固件上有几处不同：上传到屏幕可能会替换键盘自带的时钟页；使用数据线时也能看到电量；“自定义按键”和“宏”页面显示键盘本身存储的内容；有几个按键选项不提供。[要安装黑爵最新的固件吗？](/keymotion/zh-cn/help/faq/#要安装黑爵最新的固件吗)逐一说明了这些不同。

已经试过了？下面的[测试向导](#测试向导)会一步步带你完成；你也可以用自己的话[告诉我们效果如何](https://github.com/cebersaban44-rgb/keymotion/issues/new?template=keyboard.yml&title=%5BKeyboard%5D+AJAZZ+AK980+PRO+firmware+3.01&model=AJAZZ+AK980+PRO+firmware+3.01)。如果出了问题，请从**设置**发送报告：在**关于**部分的**反馈**旁边，单击**报告问题**。报告中包含 Keymotion 从键盘读取到的信息，但从不包含你的宏的内容；对于看起来不符合预期的部分，会包含它开头和结尾的字节。

装有 Keymotion 尚不认识的其他黑爵固件的 AK980 PRO 不会收到任何内容；Keymotion 会改为提供**申请适配**。

### 测试向导

如果你愿意帮我们在真实键盘上检查 3.01 固件，Keymotion 提供一个可选的测试向导：共 9 步，约 10 分钟。对于通过 USB 数据线连接、装有 3.01 固件的任何键盘，**连接**页面都会提供它；而“概览”中的邀请只在 Keymotion 还能写入键盘时才会出现。装有 1.06 固件时这两者都不会出现。你的回答属于给出它们时的固件：换成另一个固件后，向导会重新开始。

<Screenshot name="aa-guide-invite" alt="装有 3.01 固件的键盘的“概览”页面，键盘下方是邀请横幅，带有开始测试、以后再说和不再显示按钮" />

- **邀请**。“概览”只会询问一次：**开始测试**、**以后再说**（下次连接键盘时会再问一次）或**不再显示**。它是页面上的一条横幅，不是弹窗：页面照常可用。
- **固定位置**。**连接**页面上始终有**测试向导**，并显示你完成了多少；**打开向导**会打开它。
- **步骤**。准备、连接、灯效、实时灯光、逐键颜色、自定义按键、宏、屏幕（可选）和恢复。向导会一直开在页面旁边：**前往**会打开这一步需要的页面。回答**正常**、**不正常**或**已跳过**，愿意的话再写一句简短的备注；**下一步**会先要求你选择一个结果。**取消**可以在任何一步关闭向导并保存进度，Keymotion 重新启动后也能继续。
- **Keymotion 自己检查过**。凡是 Keymotion 自己能确认的地方，这一步都会打勾说明：第一次连接时的备份存在、键盘已读取并且 Keymotion 可以写入，或者在向导打开期间保存的同类设置已从键盘读回（不论是什么保存的）。它从不声称做过没有发生的检查。
- **当 Keymotion 只读取键盘时**。如果 Keymotion 目前不向键盘写入任何内容（[原因](/keymotion/zh-cn/help/recovery/#keymotion-不向键盘写入任何内容时)），向导会直接说明需要保存的步骤无法完成，并提供**报告问题**。
- **发送结果**。最后，向导会先显示将要发送的全部文字：你的回答和备注、应用和 Windows 的版本，以及 Keymotion 读取到的键盘信息（和**报告问题**中的那部分相同；从不包含你的宏的内容）。这段文字是英文的，供开发者阅读。**复制并打开 GitHub** 会把它放到剪贴板上，并打开已填好标题和键盘型号的键盘表单。GitHub 不允许 Keymotion 替你回答表单中的问题，所以向导会告诉你该选哪个答案；然后把文字粘贴到 **Keyboard details** 框中。**只复制**只复制文字。不会自动发送任何东西。

<Screenshot name="aa-guide-step" alt="“灯光”页面，旁边打开着测试向导的第 3 步“灯效”：已从键盘读回保存到键盘的灯效（Keymotion 自己检查过），前往按钮，正常、不正常和已跳过选项，备注框，以及取消、返回和下一步按钮" />

向导本身不会向键盘写入任何内容：和平时一样，由你在各个页面上保存。“屏幕”这一步可能会替换键盘的时钟页；如果想保留时钟页，请选择**已跳过**。

<Screenshot name="aa-guide-summary" alt="测试向导的最后一个画面“测试完成”：9 个步骤及其回答、要发送的文字，以及复制并打开 GitHub 和只复制按钮" />

<Aside type="caution" title="为什么不直接开放支持">
这些键盘对收到的内容不加检查就会接受。在一台 AULA F108 Pro 上，一段超出上限的屏幕动画永久覆盖了键盘自带的菜单图片。每个型号的上限都不同（107、140、141 或 255 帧），所以一个型号只有在测量出它自己的上限之后才会加入。
</Aside>

### 键盘如何逐步获得支持

1. 有这款键盘的人通过**申请适配**或[键盘表单](https://github.com/cebersaban44-rgb/keymotion/issues/new?template=keyboard.yml)发送它的信息。
2. 我们在 Keymotion 中描述这个型号，并为它准备一个测试版本。
3. 测试者逐项试过每个功能并反馈结果。每份反馈都会在 GitHub 上用 `keyboard support` 标签跟踪。
4. 所有功能都试过之后，这个型号会移到**已测试，可用**，并注明每种连接方式下可以使用的功能。

状态一栏从**尚未测试**变为**测试中**，然后是**可用**或**不可用**。

## 外观相似，内部不同

有些键盘看起来像黑爵 AK980 V2（带屏版），或者与本页某款键盘同名，但使用的是另一种芯片或另一种命令体系。Keymotion 从不向它们发送任何内容。

| 键盘 | 不同之处 |
|---|---|
| AK980 MAX（磁轴） | 另一种命令体系 |
| 黑爵 AK820 Pro，固件版本为 1.07 或 1.16 的版本 | 另一种命令体系 |
| 黑爵 AK820 MAX，使用网页设置工具的版本（包括 MAX HE） | 另一种命令体系 |
| 黑爵 AK820 Max Plus（SinoWealth 版本）、AK820（非 Pro 版）、AK992 | 另一种芯片 |
| AULA F75、F87、F87 Pro、F99、F99 Pro | 另一种芯片 |
| AULA F87S 8K、Nova98；黑爵 AK680 V2 / MAX | 另一种命令体系 |
| 黑爵 AKS068 | VIA/QMK 键盘 |

尚不清楚的型号：黑爵 AK870 V2、AK820 MAX Ultra、AK870、AK873、AK966 和 AULA F99 Max。如果你有其中一款，[发送它的信息](https://github.com/cebersaban44-rgb/keymotion/issues/new?template=keyboard.yml)，我们来弄清楚。

<p class="km-unofficial">我们对这些键盘的了解来自其他测量过它们的开源项目，包括 OpenKey、sonix-keyboard-studio、ak820pro-modder 和 OpenRGB，在此表示感谢。产品名称仅用于说明本软件适用于哪些硬件；Keymotion 与这些品牌均无关联。</p>
