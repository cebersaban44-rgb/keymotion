К каждой версии Keymotion прилагаются заметки о выпуске, в которых сказано, что изменилось.

## Где их найти

- **На GitHub.** На [странице Releases](https://github.com/cebersaban44-rgb/keymotion/releases) есть заметки к каждой версии, рядом с её установщиком и контрольной суммой SHA-256 установщика.
- **В Keymotion.** Когда Keymotion находит новую версию, нажмите **Что нового** в разделе **О программе** на странице **Настройки** или **Установить сейчас** в полосе над страницей. Окно обновления показывает заметки под заголовком **Что нового** — на языке приложения, если у выпуска есть заметки на этом языке. В противном случае в окне показывается ссылка **Заметки о выпуске на GitHub**.
- **Полная история.** Все версии перечислены на английском в файле [`CHANGELOG.md`](https://github.com/cebersaban44-rgb/keymotion/blob/main/CHANGELOG.md) на GitHub, а на турецком — в файле [`CHANGELOG.tr.md`](https://github.com/cebersaban44-rgb/keymotion/blob/main/CHANGELOG.tr.md). На русском изменения описаны начиная с версии 1.2.0 — в файле [`CHANGELOG.ru.md`](https://github.com/cebersaban44-rgb/keymotion/blob/main/CHANGELOG.ru.md).

## GitHub и Microsoft Store

Начиная с версии 1.0.0 у Keymotion один и тот же номер версии, откуда бы вы его ни получили, и один набор заметок о выпуске.

- **Настройки › О программе** в обоих случаях показывает версию одинаково: «Версия 1.0.0». В копии из Microsoft Store в той же строке сказано, что её обновляет Microsoft Store.
- **Список установленных приложений Windows** показывает копию из Microsoft Store с четвёртым числом, которое всегда равно 0: 1.0.0 отображается как 1.0.0.0. Это та же версия.
- **Когда выходит версия.** Новая версия сначала выходит на GitHub. Копия для Microsoft Store выходит следом, когда Microsoft её проверит, обычно в течение дня. Номер версии и заметки о выпуске у них одинаковые.
- **Тестовые версии** (с «-rc» или «-beta» в номере) есть только на GitHub.
- **Одновременно работает только одна копия Keymotion.** Если установлены обе, у них общие настройки. При открытии копии с GitHub вместо неё открывается копия из Microsoft Store, и автозапуск вместе с Windows тоже переходит к копии из Microsoft Store. Тестовая версия так не делает: прежде чем её открыть, закройте копию из Microsoft Store, в том числе через её значок рядом с часами. В её разделе «Настройки › О программе» тогда появляется строка «Копия с GitHub» с кнопкой, которая открывает «Установленные приложения» Windows, где можно удалить копию с GitHub. Чтобы сохранить настройки, не устанавливайте флажок **Also delete my settings and saved data** (также удалить мои настройки и сохранённые данные).

## Keymotion 1.3.0

Keymotion теперь работает и с новейшей прошивкой AJAZZ для AK980 PRO, 3.01 («769»), по USB-кабелю. Поддержка новая, поэтому она отмечена как **Бета-режим**, а необязательная пошаговая проверка спрашивает владельцев этой прошивки, как всё работает. На прошивке 1.06 ничего не меняется.

- **Прошивка AJAZZ 3.01, бета.** Эта прошивка использует другой набор команд, и Keymotion теперь знает и его: эффекты подсветки и поклавишный цвет, подсветка в реальном времени, переназначение клавиш на обоих слоях, макросы, изображения на экране, часы и уровень заряда по кабелю. Перед первой записью за сеанс Keymotion спрашивает (**Непроверенная прошивка**).
- **Безопасность прежде всего.** При первом подключении к такой клавиатуре Keymotion сохраняет резервную копию её настроек и ещё одну перед каждым восстановлением; страница **Подключение** показывает их и может вернуть. Каждая сохранённая настройка считывается с клавиатуры обратно, а прерванное сохранение исправляет следующее. Подсветка в реальном времени видна при любой подсветке клавиатуры и ничего на ней не сохраняет.
- **Пошаговая проверка.** Владельцам клавиатуры на прошивке 3.01 один раз на странице **Обзор** предлагается необязательная проверка из девяти шагов, примерно на десять минут. Она остаётся открытой рядом со страницами, отмечает то, что Keymotion может проверить сам, а в конце показывает весь текст, которым можно поделиться на GitHub. Ничего не отправляется само.
- **Короче отчёты о проблемах.** **Сообщить о проблеме** теперь описывает то, что выглядит не так, в нескольких строках, так что обычно хватает одного отчёта, и он остаётся достаточно коротким для GitHub.
- **Сначала GitHub.** Начиная с этой версии новая версия выходит на GitHub, как только её установщик прошёл проверку, а копия в Microsoft Store появляется после проверки Microsoft, обычно в течение дня.
- **Спасибо** [j0p3s](https://github.com/j0p3s) за сообщение о новой прошивке AJAZZ, проверку каждой беты на своей клавиатуре и отчёты, по которым сделана эта поддержка.

## Keymotion 1.2.1

Эта версия приносит 1.2.0 в Microsoft Store: её пакет теперь содержит `keymotion-cli` в том виде, который принимает Store. Для копии с GitHub ничего не меняется; всё новое описано ниже, в 1.2.0.

## Keymotion 1.2.0

У Keymotion новый вид в стиле Windows 11 и новые инструменты: музыкальный режим, игровая сессия с подсветкой League of Legends, профили по приложениям и подсветка для ИИ-агентов для программирования, таких как Claude Code и Codex. Приложение теперь есть и на русском, и на упрощённом китайском.

- **Новый вид.** Страницы перечислены на панели слева, как в «Параметрах» Windows; вверху панели — подключённая клавиатура и поле поиска, которое сужает список. Настройки — строки во всю ширину, а кнопки, переключатели и списки выглядят как в самой Windows. **Обзор** начинается со стеклянной панели клавиатуры, **Подсветка** показывает эффекты галереей, а библиотека на странице **Экран** стала сеткой изображений. Рисунок клавиатуры и её подсветка не изменились.
- **Музыкальный режим.** В разделе **Инструменты › Музыкальный режим** подсветка клавиш движется в такт звуку, который воспроизводит компьютер (через USB-кабель): **Столбики**, **Ритм**, **Уровень** или **Волна**, в выбранных вами цветах. Когда звук прекращается, возвращается своя подсветка клавиатуры. Keymotion считывает только текущую громкость звука: ничего не записывается, микрофон не используется. См. [Музыкальный режим](/keymotion/ru/guide/music-mode/).
- **Игровая сессия.** В разделе **Инструменты › Игровая сессия** Keymotion замечает, когда вы играете. Игры берутся из списков ваших лаунчеров (Steam, Epic Games, GOG, Xbox, Riot Games, Xbox Game Bar) и из ваших собственных отметок. Если живой экран включён, в начале игры на экран клавиатуры отправляется карточка, а в конце — итоги; клавиши, которые использует игра, могут подсвечиваться. Для игр, античит которых может быть против, есть настройка **Ничего не отправлять на клавиатуру во время игры**: клавиатура сохраняет свою собственную подсветку. См. [Игровая сессия](/keymotion/ru/guide/game-session/).
- **Подсветка League of Legends.** Во время матча, по данным, которые игра сама предоставляет на вашем компьютере: здоровье на клавишах, мана на F1–F12, тёмно-красный цвет при гибели и анимация выбранным вами цветом для победы, поражения, нового уровня, убийств, драконов, Барона и других событий. Она настраивается в списке игр у League of Legends (**Особая подсветка**), а кнопка **Проверить на клавиатуре** показывает её на клавиатуре. См. [League of Legends](/keymotion/ru/guide/game-session/#league-of-legends).
- **Профили по приложениям.** В разделе **Профили › По приложениям** можно привязать к профилю программу или все игры сразу; профиль действует, пока программа на переднем плане. По умолчанию меняется только поклавишный рисунок подсветки, и в клавиатуру ничего не сохраняется; правило может также сохранять назначение клавиш и макросы, не больше 20 раз в день. Когда игра заканчивается, клавиатура возвращается к прежним настройкам или к выбранному вами профилю. См. [По приложениям](/keymotion/ru/guide/profiles/#по-приложениям).
- **ИИ-агенты для программирования.** Claude Code и Codex могут сообщать подсветкой клавиатуры, когда закончили задачу, ждут вашего подтверждения, столкнулись с ошибкой или упёрлись в лимит использования. Это включается один раз в разделе **Инструменты › ИИ-агенты**: Keymotion сначала показывает, что будет добавлено в Claude Code и Codex, а цвет и эффект каждого сигнала выбираете вы. Агенты обращаются к Keymotion через `keymotion-cli` — инструмент командной строки, который входит в состав приложения. Если вы разрешите (каждая из этих возможностей сначала выключена), они также могут управлять таймером фокусировки, показывать подсветку профиля или выводить карточку на экран. Ничего из того, что пишете вы или агент, не попадает в Keymotion: только то, что произошло. См. [ИИ-агенты](/keymotion/ru/guide/ai-agents/).
- **Русский и упрощённый китайский.** Приложение, руководство пользователя, установщик и README теперь есть на русском и упрощённом китайском (简体中文). Если Windows работает на одном из четырёх языков, Keymotion запускается на нём, а в разделе **Настройки › Язык** язык меняется сразу. Перевод сделан с помощью ИИ и ждёт проверки носителями языка — исправления приветствуются.
- **Новая прошивка AJAZZ.** Прошивка AJAZZ 769 (3.01) использует другой набор команд. Если она стоит на AK980 PRO, Keymotion теперь сообщает об этом, ничего не отправляет клавиатуре и даёт ссылку на вопросы и ответы; поддержку планируется добавить в одном из следующих обновлений. См. [Стоит ли устанавливать новейшую прошивку AJAZZ?](/keymotion/ru/help/faq/#стоит-ли-устанавливать-новейшую-прошивку-ajazz)
- **Другие изменения.** Клавиатурой AJAZZ AK980 PRO считается только та, в USB-названии которой есть «AK980 PRO»; другая AK980 с тем же USB-идентификатором, например без экрана, теперь получает кнопку **Запросить поддержку**. Если версия прошивки не проверялась с Keymotion, часы клавиатуры тоже ждут вашего согласия. На сайте появилась страница [Условия использования](/keymotion/ru/about/terms/).
- **Исправления.** В ночь перевода часов назад напоминание или встреча в этот час больше не срабатывает на час раньше, а события из календарей Outlook в некоторых часовых поясах больше не сдвигаются на час; некоторые повторяющиеся события больше не пропадают и не появляются не в те дни. Если подключён только приёмник 2,4 ГГц, Keymotion больше не пишет, что клавиатура работает. Если включён **Предпросмотр на клавиатуре**, после закрытия окна предпросмотр больше не остаётся на клавишах. На экране клавиатуры название песни, встречи или напоминания, которое заканчивается на «…», больше не рисуется самым мелким шрифтом.

## Keymotion 1.1.0

Теперь Keymotion сообщает о выходе новой версии и может установить её автоматически. Приложение также есть в Microsoft Store.

- **Уведомления об обновлениях.** Уведомление Windows сообщает о выходе новой версии — один раз для каждой версии — с кнопками **Обновить сейчас** и **Позже**. Об этом также сообщают меню значка Keymotion рядом с часами и карточка в левом нижнем углу окна, так что вы увидите это, даже когда Keymotion работает с закрытым окном.
- **Автоматическое обновление.** В разделе **Настройки › О программе › Обновления** выберите **Обновлять автоматически**, **Уведомлять** или **Выключено**. При автоматическом обновлении новая версия скачивается и устанавливается, пока вы не пользуетесь компьютером, и никогда — во время записи в клавиатуру. См. [Обновления](/keymotion/ru/guide/settings/#обновления).
- **После обновления** уведомление сообщает, какая версия установлена, и Keymotion открывается в том же виде, что и раньше.
- **Microsoft Store.** Keymotion есть в Microsoft Store, и копия оттуда подписана Microsoft. Если установлены обе копии, копия с GitHub вместо себя открывает копию из Microsoft Store. Когда Microsoft Store устанавливает новую версию, Keymotion снова открывается автоматически.

## Keymotion 1.0.0

То же приложение, что и 0.1.0, подготовленное для Microsoft Store. Microsoft Store не принимает номера версий, которые начинаются с 0, поэтому этот выпуск получил номер 1.0.0.

- **Выпуск для Microsoft Store.** Microsoft подписывает копию в Microsoft Store, поэтому Windows устанавливает её без предупреждения. Keymotion, установленный из Microsoft Store, обновляется через Microsoft Store и запускается вместе с Windows через параметры автозагрузки Windows. Версия на GitHub работает как прежде.

## Keymotion 0.1.0

Первый выпуск. Поддерживает AJAZZ AK980 PRO в Windows.

- **Подключение.** Находит клавиатуру через USB-кабель, приёмник 2,4 ГГц и Bluetooth. Для настроек нужен USB-кабель; через Bluetooth показывается уровень заряда.
- **Обзор.** Вся клавиатура с подписями каждой клавиши, то, что сейчас показывает экран, и плитка для каждого инструмента.
- **Подсветка.** 19 встроенных эффектов, поклавишная подсветка с кистью и инструментами выделения, а также калибровка цвета.
- **Назначение клавиш и макросы.** Основной слой и слой Fn, сброс к заводскому назначению и макросы, которые записываются нажатием клавиш.
- **Экран.** Изображения, GIF, видео, текстовые карточки и слайд-шоу для экрана 240×135, библиотека и способ вернуть заводскую анимацию. У Keymotion также есть собственная анимация.
- **Живой экран.** Карточки, которые обновляются сами: песня, которая сейчас играет, таймер фокусировки и предстоящие встречи — в пределах дневного лимита загрузок.
- **Инструменты.** Таймер фокусировки, напоминания, карточки календаря из Google Календаря, Outlook и iCloud, а также системные показатели на клавишах.
- **В фоне.** После закрытия окна Keymotion продолжает работать, а его значок остаётся рядом с часами; приложение может запускаться вместе с Windows.
- **Обновления и сообщения о проблемах.** Keymotion проверяет на GitHub, нет ли новых версий, и устанавливает их только по вашему выбору. О проблемах вы сообщаете на GitHub сами.
- **Установщик.** Только для вашей учётной записи Windows, на английском и турецком, без прав администратора.
- Интерфейс на турецком и английском, светлая и тёмная темы.

Keymotion 0.1.0 пока не подписан цифровой подписью. См. [политику подписи кода](/keymotion/ru/about/code-signing/).
