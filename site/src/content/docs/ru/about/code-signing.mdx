Подпись кода позволяет Windows показать, кто выпустил программу и что с тех пор её никто не изменял. На этой странице объясняется, как выпуски Keymotion собираются, подписываются и проверяются.

## Текущее состояние

Keymotion можно получить двумя способами. Копия из [Microsoft Store](https://apps.microsoft.com/detail/9NL03GDZZ0ZS?referrer=appbadge&mode=full) подписана Microsoft, поэтому устанавливается без предупреждения. Установщик на GitHub пока не подписан цифровой подписью, поэтому при его запуске Windows может показать предупреждение; как продолжить, показано на странице [Установка Keymotion](/keymotion/ru/guide/install/).

15 ноября 2026 года проект подал заявку в SignPath Foundation, которая бесплатно предоставляет подпись кода проектам с открытым исходным кодом. SignPath пока отказала, потому что проект ещё новый, и предложила подать заявку снова, когда он станет более известным. Проект так и сделает.

В Microsoft Store корпорация Microsoft проверяет каждый пакет перед публикацией и подписывает его. Пакет в Microsoft Store содержит ту же программу, что и установщик на GitHub, и собирается с помощью GitHub Actions из того же тега версии.

## Как собираются выпуски

- Каждый выпуск собирается с помощью GitHub Actions из исходного кода своего тега версии рабочим процессом [`.github/workflows/release.yml`](https://github.com/cebersaban44-rgb/keymotion/blob/main/.github/workflows/release.yml). Файлы выпуска никогда не собираются на личном компьютере и не загружаются с него.
- Рабочий процесс размещает выпуск на GitHub в виде черновика. Сопровождающий проекта проверяет его и публикует.
- На [странице выпусков](https://github.com/cebersaban44-rgb/keymotion/releases) указана контрольная сумма SHA-256 установщика, чтобы вы могли убедиться, что скачали именно опубликованный файл.

Чтобы сравнить контрольную сумму:

<Steps>

1. Откройте папку, в которую вы сохранили установщик, например **Загрузки**.
2. Щёлкните правой кнопкой мыши пустое место в папке и выберите **Открыть в Терминале**.
3. Введите `Get-FileHash`, а после него имя установщика, например `Get-FileHash .\Keymotion_0.1.0_x64-setup.exe`, и нажмите Enter.
4. Сравните длинный код, который появится, с SHA-256 на странице выпуска. Они должны совпадать.

</Steps>

## Проверка антивирусами

Установщик Keymotion 0.1.0 был проверен на VirusTotal 15 ноября 2026 года. Из 71 антивируса 70 ничего не нашли, включая Microsoft Defender.

Один антивирус, Trapmine, отмечает установщик по оценке машинного обучения («Malicious.high.ml.score»), а приложению внутри установщика та же модель даёт низкую оценку. Это предположение, которое антивирус делает о новых неподписанных файлах, а не совпадение с известной вредоносной программой. 15 ноября 2026 года мы сообщили Trapmine об этом как о ложном срабатывании. Подписанные выпуски должны сделать такие предположения более редкими.

- [Отчёт VirusTotal об установщике](https://www.virustotal.com/gui/file/f2a1208007ba947c5ec082835328b8dbb0240baa22839d8ea439d1423f897531)

## Как проверяются обновления

Каждый установщик также подписывается собственным ключом обновлений Keymotion. У ключа две половины:

- закрытая половина хранится в секрете у проекта, и рабочий процесс выпуска подписывает ею каждый установщик;
- открытая половина встроена в Keymotion.

Когда Keymotion скачивает обновление, скачанный файл проверяется с помощью открытой половины. Если подпись не совпадает, обновление не устанавливается и появляется сообщение «Не удалось проверить подлинность скачанного файла, поэтому он не установлен». Таким образом, Keymotion устанавливает только обновления, подписанные ключом проекта.

<Aside type="note" title="Не то же самое, что подпись кода в Windows">
Ключ обновлений защищает обновления, которые устанавливаются из самого Keymotion. Он не влияет на предупреждение, которое Windows может показать, когда вы запускаете установщик, скачанный вами самостоятельно.
</Aside>

## Запросы на подпись

Когда подпись будет настроена, каждый запрос на подпись будет вручную утверждаться одним из утверждающих, прежде чем что-либо будет подписано.

## Конфиденциальность

Keymotion не собирает данные об использовании. Приложение выходит в интернет только для того, чтобы читать добавленные вами календари и проверять на GitHub, нет ли новой версии. См. [политику конфиденциальности](/keymotion/ru/about/privacy/).
