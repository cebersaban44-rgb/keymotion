Short answers to the questions people ask most. For step-by-step fixes, see [If something goes wrong](/keymotion/help/recovery/).

## Why does Windows warn me when I install Keymotion?

Keymotion's installer on GitHub isn't code-signed yet, so Windows may stop it with "Windows protected your PC". Download the installer only from the project's [GitHub Releases page](https://github.com/cebersaban44-rgb/keymotion/releases). Then click **More info** and **Run anyway**.

SignPath Foundation, which signs open-source projects for free, declined for now because the project is still new; it will apply again. To install without the warning, get Keymotion from the [Microsoft Store](https://apps.microsoft.com/detail/9NL03GDZZ0ZS?referrer=appbadge&mode=full): Microsoft signs its copy. See the [code signing policy](/keymotion/about/code-signing/) and [Installing Keymotion](/keymotion/guide/install/).

If **Smart App Control** is on (Windows Security, **App & browser control**), Windows may block the installer outright, with no **Run anyway** button, because it isn't signed. We don't ask you to turn Smart App Control off for Keymotion; the [Microsoft Store](https://apps.microsoft.com/detail/9NL03GDZZ0ZS?referrer=appbadge&mode=full) copy installs with it on.

## Is the Microsoft Store version different from the one on GitHub?

No. It is the same app with the same version numbers and the same release notes. What differs: the Store updates its copy (the app's own update check stays off), and Windows shows its version with a fourth number, always 0 (1.0.0.0). A new version comes out in both the same day, once Microsoft has reviewed the Store's copy. Test versions are only on GitHub. One copy is enough: with both installed, the GitHub copy opens the Store's copy instead; see [GitHub and the Microsoft Store](/keymotion/about/release-notes/#github-and-the-microsoft-store).

## My antivirus or VirusTotal flags Keymotion. Is it safe?

For Keymotion 0.1.0, 70 of the 71 antivirus engines on VirusTotal find nothing, Microsoft Defender included. The one that flags it, Trapmine, gives new, unsigned files a machine-learning score; it isn't a match with known malware, and we've reported it as a false positive.

Download Keymotion only from the GitHub Releases page and compare the SHA-256. The VirusTotal report is in the [code signing policy](/keymotion/about/code-signing/#antivirus-scans).

## Does it work with AJAZZ's official software open?

You can keep AJAZZ's software installed. While its driver is running, though, Keymotion doesn't save anything to the keyboard and says "The AJAZZ driver is running. Close it before saving to the keyboard." The same goes for SignalRGB and OpenRGB.

The keyboard follows one program's commands at a time, and commands from two programs can mix up. Close the other program, then save again.

Having the driver installed is also useful: Keymotion can copy the keyboard's factory screen animation from it. See [If something goes wrong](/keymotion/help/recovery/#put-the-factory-screen-animation-back).

## Do I need AJAZZ's software to use Keymotion?

No. Keymotion talks to the keyboard by itself over the USB cable and does all of it on its own: lighting, key mapping, macros and the screen. You can uninstall AJAZZ's software.

Keeping it installed has one use: if you ever want the keyboard's factory screen animation back, Keymotion can copy it from there. See [If something goes wrong](/keymotion/help/recovery/#put-the-factory-screen-animation-back).

## Do I need a driver for the AK980 PRO?

No. Windows recognizes the keyboard by itself, so typing, the media keys and the knob work without installing anything. What AJAZZ calls the keyboard's driver is a settings program. Keymotion does that job instead, and it installs no driver of its own. It also needs no administrator rights to install.

## How do I put a GIF or my own picture on the AK980 PRO screen?

1. Connect the USB cable and set the switch on the back of the keyboard to the middle.
2. In Keymotion, open **Screen** and choose **Image or video**.
3. Pick a PNG, JPEG, GIF, WebP, APNG, MP4 or WebM file, then place it and choose the part you want.
4. Click **Preview**, then **Upload to keyboard**.

A still picture uploads in a few seconds. The screen holds up to 140 frames, and a full 140-frame animation takes about five and a half minutes. On the keyboard, **Fn+Home** switches between the clock and your picture. You can also make text cards and slideshows: see [Screen](/keymotion/guide/screen/).

## Does Keymotion work on macOS or Linux?

No. Keymotion runs on Windows 10 and 11, 64-bit.

## Why can't I change settings over Bluetooth?

Over Bluetooth, the keyboard offers typing and its battery level, but no way to change its settings. So Keymotion only reads the battery there. To change settings, connect the USB cable and set the switch on the back to the middle.

Over the USB cable it's the other way round: the keyboard doesn't report its battery, so Keymotion shows the last Bluetooth reading and how long ago it was taken.

## What about the 2.4 GHz receiver?

You can type over the receiver as usual. Keymotion sees that the receiver is plugged in, but it doesn't talk to it yet, so it can't tell whether the keyboard behind it is turned on, and settings can't be changed over the receiver. Use the USB cable to change them. [Connection](/keymotion/guide/connection/) shows what works in each mode.

## Can Keymotion break my keyboard?

Keymotion is built to be careful with the keyboard:

- It sends only commands that were tested on this keyboard. Anything else is blocked before it leaves your computer, including the commands that would start a firmware update. Keymotion never updates the keyboard's firmware, and over Bluetooth it writes nothing at all.
- Your settings go to the keyboard's permanent memory only when you choose to save or upload, for example with **Save to keyboard**. Previews aren't saved.
- Before saving, it checks. If your keyboard's firmware version hasn't been tested with Keymotion, it asks you first, and it doesn't set the keyboard's clock either until you say yes. Live lighting, which the keyboard doesn't keep, goes on without asking. If it doesn't recognize the firmware, it sends nothing. While another program is using the keyboard, or more than one keyboard is connected by USB, it doesn't save.
- If you close Keymotion while it's saving, it waits and closes when the save is done. If you shut down Windows, Windows shows that Keymotion is still saving to the keyboard.

The screen's memory wears out slowly with each upload. Its exact lifespan isn't known; by the usual estimate for this kind of memory, a few uploads a day are fine for years. The live screen has a daily upload limit for this reason.

<Aside type="caution" title="At your own risk">
Writing to a device's permanent memory can always leave it in an unwanted state, and Keymotion comes without any warranty. Most changes can be undone: see [If something goes wrong](/keymotion/help/recovery/).
</Aside>

## Do I need to keep Keymotion open?

No, not for what you save. Lighting, key assignments, macros and the screen picture are saved on the keyboard itself.

The focus timer, reminders, calendar cards, the live screen, the system gauges, the game session and profiles by app need Keymotion running. When you close its window, Keymotion keeps running with an icon next to the clock. You can change this in **Settings**, under **Closing and starting**. See [Settings](/keymotion/guide/settings/).

## Is Keymotion safe to run with games and anti-cheat software?

Keymotion doesn't read or change a game's memory, doesn't send keys to games and installs no driver. It sees which program is in front the way Windows' accessibility tools do, and during a League of Legends match it reads only the data the game itself offers on your computer. If a game's anti-cheat software still gives you trouble, turn on **Send nothing to the keyboard while playing** on the [Game session](/keymotion/guide/game-session/#anti-cheat-software) page.

Macros, even the keyboard's own, can break the rules of competitive games such as League of Legends, VALORANT and CS2. Keymotion never turns macros on for a game by itself.

[Music mode](/keymotion/guide/music-mode/) doesn't touch a game's code or memory either: it reads only the mixed sound Windows sends to your speakers, as call and streaming apps do, and it never shows left and right apart. Its **Pause while playing a game** is on at first.

## Does music mode listen to my microphone?

No. It reads only the sound your PC plays, on its way to your speakers or headphones, and only how loud it is right now. Nothing is recorded, stored or sent anywhere.

## Why don't the music lights react to some apps?

Some music players can keep the sound to themselves (often called exclusive mode in their settings), and some protected films and series in streaming apps aren't shared either. Windows then gives that sound to no other program, so the lights stay still. Music mode also follows Windows' default output: if the sound plays on another device, choose that one in Windows' sound settings.

## Where are my settings stored?

On your computer, in your Windows user folder:

- settings and records in `%APPDATA%\dev.keymotion\`;
- log files in `%LOCALAPPDATA%\dev.keymotion\logs\`.

In **Settings**, under **About**, **Data folder** and **Log files** open them. Keymotion's records of your key mapping and macros are the only copy, because the keyboard can't report them. To keep a copy, open **Settings** and click **Export** under **Backup**: it saves everything in one file. The full list is in the [privacy policy](/keymotion/about/privacy/#where-your-data-lives).

## Does Keymotion send data anywhere?

No. It collects no usage data, has no account and sends nothing about you or your computer. It goes online only to read the calendars you add and to check GitHub for a new version. Problem reports go to GitHub only when you send them yourself. Details are in the [privacy policy](/keymotion/about/privacy/).

## Codex asks me to approve new hooks. Should I?

Yes, if you connected Codex on the **AI agents** page. Codex asks once to trust the hooks Keymotion added: type `/hooks` in Codex, or open Settings › Hooks in the Codex app, and approve them. Until then, Keymotion shows **Waiting for your approval in Codex once**, and Codex doesn't tell Keymotion when a task finishes or waits for you. The hooks stay the same when Keymotion updates, so Codex doesn't ask again. See [AI agents](/keymotion/guide/ai-agents/).

## What should I do before uninstalling Keymotion?

If you connected Claude Code or Codex on the **AI agents** page, remove the connections first: open **AI agents**, click the arrow next to each app and choose **Remove connection**. Claude Code calls Keymotion's command-line tool directly, so once Keymotion is gone it reports a hook error on every event until the connection is removed. This matters most for Keymotion from the Microsoft Store: Windows removes it without letting it clean up after itself.

If you've already uninstalled it, install Keymotion again and remove the connections, or delete the hooks that name `keymotion-cli` from `%USERPROFILE%\.claude\settings.json` yourself.

## Does it work with other keyboards?

Not yet. Keymotion supports the AJAZZ AK980 PRO. If you connect a SONiX or AJAZZ keyboard that isn't supported yet, Keymotion says so, sends nothing to it, and offers **Request support** to ask for it on GitHub. See [Supported keyboards](/keymotion/help/keyboards/).

## Does it work with the AJAZZ AK980 V2?

Yes. The keyboard Keymotion is tested with was sold as the AK980 V2: AJAZZ's store listed it as "AK980MAX … V2" and the box says "AK980 V2". Over USB it gives SONiX as its maker and "AK980 PRO" as its name, and Keymotion recognizes it by that name. What matters is the hardware: the 98-key model with the 240×135 screen and the knob. See [Supported keyboards](/keymotion/help/keyboards/).

## My keyboard isn't recognized after a firmware update

A firmware update, for example from AJAZZ's software, can change how the keyboard identifies itself. If Keymotion no longer recognizes it, it sends nothing to the keyboard and shows **This keyboard isn't supported yet** with **Request support**. Click it, then **Report on GitHub**: the keyboard's details go to the clipboard and the project's form opens on GitHub. Paste them into the form's details box (Ctrl+V) and send it; those details are what we need to support the new firmware. Nothing is written to the keyboard.

If Keymotion still recognizes the keyboard but says its firmware hasn't been tested, it keeps working and asks you before saving to the keyboard. See [Can Keymotion break my keyboard?](#can-keymotion-break-my-keyboard)

## Is Keymotion made by AJAZZ?

No. Keymotion is an independent project. It isn't affiliated with, endorsed, sponsored or supported by AJAZZ, by the maker of the keyboard's controller chip, or by the authors of the keyboard's official software. The AJAZZ name is used only to say which keyboard Keymotion works with.

## How is Keymotion made?

I made Keymotion with Claude, an AI coding assistant. Claude wrote most of the code; I decided what it should do and tried every feature on my own AK980 PRO before it went in. Every change goes through a pull request and automatic checks. Everything that talks to the keyboard was measured on the real keyboard first, and commands that could harm it, such as firmware updates, are blocked in the code. The source code is public, so you can read exactly what Keymotion does.

## Is it free?

Yes. Keymotion is free and open source, under the MIT or Apache 2.0 license, at your choice. There's no account and nothing to buy. The source code is on [GitHub](https://github.com/cebersaban44-rgb/keymotion).

## How do I report a problem?

Open **Settings**. Under **About**, next to **Feedback**, click **Report a problem**. A window shows the details that will be included. **Report on GitHub** copies them and opens the project's form on GitHub, where you paste them and send it. You need a GitHub account. Nothing is sent until you do.
